# BrutForce / Брютфорс

Brut (брют) + Force (сила), с отсылкой к brute force.

Приватный монорепозиторий команды ЛЦТ 2026. Выбранная задача РСХБ: поиск карточки российского вина по фотографии этикетки на платформе «Свое Вино».

Статус: репозиторий создан; архитектура обсуждается. Исполняемого приложения, установленных зависимостей и измеренных результатов пока нет.

## Основание продукта

Смысловое ядро команда сформулирует позже. Пока опираемся на официальную задачу РСХБ «Сканер российских вин с описанием на платформе Свое Вино»:

> Разработайте сервис, который после сканирования по фотографии на основе обработки массива вин на платформе Свое Вино сможет найти нужную карточку вина с описанием.

[Публичная формулировка](https://i.moscow/hackaton/lct/3a9c0c2e86184425bd73d4cedbf6565a) · [Карточка в личном кабинете для доступа к ТЗ](https://i.moscow/cabinet/hackaton/lct/contest/3a9c0c2e86184425bd73d4cedbf6565a).
Цитата взята из публичной карточки, прочитанной 14 сентября 2026. Прямая ссылка на текст полного ТЗ и его содержание пока не проверены; не считать краткую карточку полным ТЗ. Продуктовые приоритеты и дополнительные требования за владельца не придумываем.

Рабочий принцип: минимум структуры под текущую задачу; новые документы, инструменты и уровни разделения добавляем по мере работы.
