## Быстрый запуск

Это локальное **синтетическое демо**, без распознавания этикетки. Нужны Go 1.23, Node.js 22 и npm; база данных не требуется. Для запуска реальной модели нужны внешние assets и [пошаговый runbook](docs/RUNBOOK.ru.md#полный-cpu-профиль-f8).

В первом терминале из корня репозитория:

```sh
mkdir -p ./local-uploads
cd apps/api
UPLOAD_DIR="$(pwd)/../../local-uploads" go run .
```

Во втором терминале из корня репозитория:

```sh
cd apps/web
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5190/> и проверьте API: `curl --fail http://127.0.0.1:8097/v1/health`. Остановите оба процесса Ctrl-C. Снимки в `local-uploads/` удаляет только владелец данных; не публикуйте их. Конкурсный endpoint в демо отвечает `503 recognition_unavailable`.

## Реальный запуск и результаты

На Linux x86-64 с Docker Engine/Compose v2 нужны полученные от владельца **вне Git** F8 bundle, пакет каталога и media, отдельный индекс рекомендаций. [Runbook](docs/RUNBOOK.ru.md#полный-cpu-профиль-f8) даёт порядок получения, настройки, проверки, запуска и остановки; [50 SHA](deploy/assets/f8-cpu.sha256) фиксируют состав model bundle. Repro собрал оба linux/amd64-образа на OrbStack в отдельной patch-ветке; в `main` ещё есть TS blocker. Передача bundle и запуск на чистом Linux пока не подтверждены. Действующий PROD использует systemd.

В TEST и [PROD](https://app.dzap.pw) на 28 сентября 2026 работает CPU F8: приложение `d26afa3`, candidate `b0428147…`, каталог `svoe-20260927-alpha-2035-v1`, индекс рекомендаций `f05f16c7…`. Документация впервые вошла в приватный `main` на `b451ecd`; её SHA может быть новее и не обозначает выпущенный код. [Связка версий и схема](ARCHITECTURE.md).

В PROD оригинальный проверочный скрипт получил непустой `slug` для **3 из 3** контрольных фото за **4,595 / 4,354 / 3,079 с**; известный ответ первого фото совпал. Это HTTP smoke, без вывода об общей точности или p95. Цели ТЗ — 90–100% и <3 с; остальные измерения и границы проверки — в [результатах](docs/SOLUTION.md). Ops прошёл в headless-браузере текстовый маршрут главная → поиск → карточка → рекомендации на 390×844 и 320×640 без ошибок; визуальная геометрия, gallery/photo-result и физическая камера ещё не проверены.

## Система кратко

```text
браузер (React/TypeScript) → Go API ──→ PostgreSQL (карточки)
                                ├──→ приватные фото и feedback (вне web-root)
                                └──→ CPU F8 vision (отдельный сервис и assets вне Git)
```

Конкурсный `POST /v1/eval/predict` принимает multipart `image` и выдаёт проверенный slug ([контракт](contracts/eval-predict.md)). Приложение сопоставляет его с карточкой каталога. Отдельный индекс рекомендует карточки по тексту витрины и атрибутам винодельни; он не предсказывает вкус. [Полная схема](ARCHITECTURE.md).
