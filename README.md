# BrutForce — сканер российских вин

Проект команды соревнования **«Лидеры цифровой трансформации — 2026»** по кейсу платформы «Своё Вино». Задача — по фотографии этикетки найти точную запись в каталоге российских вин и открыть её карточку на телефоне. Решение сочетает распознавание изображения, поиск по каталогу и мобильное веб-приложение. При отсутствии подтверждённой карточки приложение не выдаёт другое вино за точное совпадение.

**Команда:** Максим Попков ([Telegram @skifmax](https://t.me/skifmax)) и Роман Карандашов ([GitHub MisterMolox](https://github.com/MisterMolox)). [English](README.en.md).

## Что можно запустить

| Режим | Без Docker | С Docker | Что работает |
|---|---|---|---|
| Минимальный, без внешних данных | [Go + Node.js](docs/SELF-HOST.ru.md#минимальный-режим-без-docker) | [Один контейнер](docs/SELF-HOST.ru.md#минимальный-режим-с-docker) | Мобильный интерфейс, восемь явно демонстрационных карточек, поиск по названию, загрузка фото. Распознавания вина нет: конкурсный API честно отвечает 503. |
| Полный, с данными и моделью | [Состав и ручная сборка](docs/SELF-HOST.ru.md#полный-режим-без-docker) | [Compose](docs/SELF-HOST.ru.md#полный-режим-с-docker) | Реальный каталог, поиск по этикетке, карточки и рекомендации при наличии точного комплекта модели, индекса и каталога. |

**Начать без данных:** установите Go 1.23 и Node.js 22; команды ниже выполняются из корня клона на macOS или Linux. Никаких паролей и токенов команды не требуется.

```sh
npm --prefix apps/web ci
npm --prefix apps/web run build
mkdir -p local-uploads
cd apps/api
UPLOAD_DIR="$(pwd)/../../local-uploads" WEB_ROOT="$(pwd)/../web/dist" go run .
```

Откройте <http://127.0.0.1:8097/>. Проверка: `curl --fail http://127.0.0.1:8097/v1/health`. Остановка — Ctrl-C; личные фото в `local-uploads/` остаются у владельца. Запуск минимального режима **с Docker** и обе процедуры полного режима приведены в [инструкции](docs/SELF-HOST.ru.md).

Полный комплект включает код и веса сервиса компьютерного зрения, его визуальный индекс и список допустимых slug, пакет каталога с изображениями и отдельный индекс рекомендаций. **Эти байты не входят в репозиторий.** Публичного способа получить весь согласованный комплект без участия владельца данных сейчас нет; проверка SHA позволяет проверить полученный комплект, но не скачать его. Полный самостоятельный запуск на чистой машине пока не подтверждён — [точные ограничения](docs/SELF-HOST.ru.md#состояние-полного-комплекта). Это ограничение данных, а не требование токена к нашему API.

## Где находятся части решения

- `apps/web/` — интерфейс React/TypeScript; `apps/api/` — Go API, приватные фото и доступ к каталогу PostgreSQL.
- `deploy/compose.demo.yaml` — минимальный Docker без базы и ML; `deploy/compose.yaml` — полный профиль с PostgreSQL и сервисом распознавания.
- `scripts/asset-bundle.py` и `deploy/assets/f8-cpu.sha256` — состав и проверка внешнего комплекта модели; `scripts/docker-local.sh` — запуск полного профиля.
- [Архитектура](ARCHITECTURE.md) объясняет путь фото и разницу между [конкурсным API](contracts/eval-predict.md) и [API приложения](contracts/vision-serving.md). Организатор отправляет `POST /v1/eval/predict` с multipart-полем `image` и получает один `{"slug":"..."}`. Приложение загружает фото через `/v1/photos` и ищет по `photoId` через `/v1/search`.
