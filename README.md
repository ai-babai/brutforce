# BrutForce / Vino

Основной проект команды ЛЦТ 2026 по задаче РСХБ: найти точную карточку
российского вина по фотографии этикетки на платформе «Своё Вино».

С 17 сентября 2026 года подготовленный проект Vino принят как основа
репозитория BrutForce. В репозиторий перенесены правила, нормализованные
требования, архитектурные границы, Agents OS, контракты данных, воспроизводимый
код подготовки наборов и компактные результаты аудита. Исходные фотографии,
закрытые материалы, большие таблицы, веса и индексы хранятся вне Git.

## Данные

Канонический логический корень — [Dataset](Dataset/README.md). В Git находятся
только контракты, provenance, README, безопасные summary и код сборки. Полный
проверенный data-only пакет создаётся скриптом
[`scripts/build-parsed-dataset-package.ps1`](scripts/build-parsed-dataset-package.ps1)
и размещается на сервере в версионированной папке `/srv/lct/data/roman/vino/`.

Актуальный пакет от 17 сентября 2026 года содержит 32 885 файлов, имеет размер
3 982 310 819 байт и SHA-256
`a3bc9d8bd6d8b1524a46354b4c8f1bb7a7d06964c9dd17325a07b8b22809b8d8`.
Состав и ограничения передачи описаны в
[Dataset/PARSED-DATASET-TRANSFER.md](Dataset/PARSED-DATASET-TRANSFER.md).

## Техническая граница

Обязательное ядро — визуальный CV retrieval конкретной этикетки с честным
`not_found` и контролем near-duplicate ошибок. OCR, текстовый embedder BGE-M3,
LLM и BGE reranker рассматриваются как дополнительные сигналы; они не заменяют
image encoder и визуальный индекс. Конкретный стек фиксируется только после
сравнительного baseline и ADR.

Полный текст ТЗ и приватные наборы не коммитятся. Их нормализованное содержание
и трассировка находятся в [PROJECT.md](PROJECT.md) и
[docs/product/ACCEPTANCE-MATRIX.md](docs/product/ACCEPTANCE-MATRIX.md).

## Проверка checkout

```powershell
.\scripts\verify-project-setup.ps1
```

Команда выше проверяет Git metadata без закрытых файлов. На машине, где
подключён полный `Dataset/` и локальный PDF ТЗ, используется
`.\scripts\verify-project-setup.ps1 -FullData`.
