# BrutForce / Брютфорс

Brut (брют) + Force (сила), с отсылкой к brute force.

Приватный монорепозиторий команды ЛЦТ 2026. Выбранная задача РСХБ: поиск карточки российского вина по фотографии этикетки на платформе «Свое Вино».

Статус: репозиторий создан; архитектура обсуждается. Исполняемого приложения, установленных зависимостей и измеренных результатов пока нет.

- [Правила для агентов](AGENTS.md)
- [Документация и варианты решения](docs/README.md)
- [Правила контрактов между частями системы](contracts/README.md)
- [Официальная карточка задачи](https://i.moscow/hackaton/lct/3a9c0c2e86184425bd73d4cedbf6565a)

Один репозиторий должен содержать приложение, сервер, поиск и небольшие материалы оценки после согласования структуры. Датасеты и веса хранятся вне Git. Публикация, выбор лицензии и доступ других участников отдельно не настраивались.
