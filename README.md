# BrutForce / Брютфорс

Приватный монорепозиторий команды ЛЦТ: поиск карточки российского вина по фотографии этикетки на платформе «Свое Вино».

## Первая реализация · 19.09.2026

Мобильный пользовательский путь по Wine UX Atlas. Go API и React + TypeScript.
Распознавание и две карточки — **явно обозначенные синтетические заглушки**.
Фото загружается в приватное хранилище сервера, вне Git и публичных файлов. Демо не измеряет качество модели и не реализует
непроверенный конкурсный API. Задача: https://github.com/ai-babai/brutforce/issues/19.

## Локальный запуск

Терминал 1:
```sh
cd apps/api
UPLOAD_DIR=/tmp/brutforce-demo-photos go run .
```
Терминал 2:
```sh
cd apps/web
npm ci
npm run dev
```
Открыть http://127.0.0.1:5190/. API на 127.0.0.1:8097.

## Путь от идеи к проверке

- `docs/product/idea-inbox.md` — исходные мысли человеческим языком.
- `docs/product/behavior-spec.md` — конкретные Given / When / Then и границы.
- `cases/cases.json` — стабильные ID и связи с проверками.
- `apps/web/` — мобильный UI, локальные инструкции, быстрые компонентные тесты.
- `apps/web/design-specs.md` — отдельные требования к виду экранов и границы быстрых дизайн-проверок.
- `apps/api/` — HTTP API, локальные инструкции, Go httptest без отдельного сервера.
- `contracts/` — каноническая схема границы; это контракт демо.
- `reports/` — один интерактивный дашборд и история запусков.
- `scripts/` — сбор результатов реально выполненных проверок.
- `design/wine-ux-atlas/` — исходные макеты, референсы, правила и история дизайна.
- `deploy/` — отдельный сервис демо и маршруты Caddy с откатом.

После правки выполнять затронутые быстрые тесты; перед передачей — общий прогон
с отчётом (команда в `reports/README.md`). Не ослаблять проверки ради зелёного.
Непроверенное не окрашивать зелёным. DOM-тесты не доказывают геометрию на телефоне,
физическую камеру и точность распознавания; это отдельные виды проверки.

## Источники и ограничения

[Публичная задача РСХБ](https://i.moscow/hackaton/lct/3a9c0c2e86184425bd73d4cedbf6565a):
фото этикетки → соответствующая существующая карточка с описанием.
Уже изучена запись Q&A РСХБ, сводка хранится локально вне Git:
`/Users/skif/ml-data/brutforce/materials/2026-09-18-rshb-qa/SUMMARY.md`.
Полное актуальное ТЗ и оценочный скрипт не найдены; публичная страница при проверке
19.09.2026 недоступна инструменту чтения. Формат slug/confidence, таймаут и правила
винтажей нельзя считать проверенными. Это не блокирует разрешённый UX-прототип.

Датасеты, веса, реальные пользовательские фото, секреты — вне Git.
См. AGENTS.md, docs/README.md и contracts/README.md. Старые варианты архитектуры —
обсуждения, а не описание текущего работающего демо.

Общий прогон: `RUN_LABEL="Название реализации" node scripts/run-fast-checks.mjs`.
