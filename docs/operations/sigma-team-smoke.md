# Smoke-проверка делегирования Sigma

1. OpenCode выполняет порученную задачу, оставляет проверяемый результат и сам переводит карточку в статус `Sigma verification`.
2. Независимый Hermes проверяет результат; после этого человек принимает его в `Human verification`.

Автоматический повторный запуск запрещён: повторов без отдельного решения нет. Новая попытка разрешена только по явному запросу через Telegram.
