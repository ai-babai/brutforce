# Документация BrutForce

Начните с [описания задачи и демонстрации](../README.md). Для первого запуска серверы команды не требуются.

## Внешний маршрут

1. [Самостоятельный запуск](SELF-HOST.ru.md) — требования, минимальный режим без данных, Docker/без Docker, формат полного комплекта, конфигурация и проверочные запросы.
2. [Архитектура](../ARCHITECTURE.md) — UI, Go API, компьютерное зрение, каталоги, путь фото и различие конкурсного и пользовательского API.
3. [Результаты и ограничения](SOLUTION.md) — что проверено на данных и что остаётся недоступным для независимого полного воспроизведения.
4. [Контракты API](../contracts/README.md) — запросы и ответы для интеграции.
5. [Перенос данных и построение индексов](ASSET-TRANSFER.ru.md) — назначения внешних каталогов, целостность архива и отдельные генераторы визуального и текстового индексов.

[English entry](../README.en.md) links to the same source-of-truth guides.

- [Порядок выпуска](../deploy/PIPELINE.md) — CI, контроллер, разрешение PROD и откат.
