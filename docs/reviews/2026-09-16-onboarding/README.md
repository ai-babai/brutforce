# Проверка входа независимыми агентами Terra

Дата: 2026-09-16. Проверяющая модель: GPT-5.6-terra. Три независимых агента запускались с fork_turns=none, без истории основного разговора. Это ручной приёмочный прогон инструкций, не постоянный тестовый набор или CI.

## Что создано

Пакет [agent-guide](../../agent-guide/AGENTS.md) в существующем приватном репозитории BrutForce. Отдельный репозиторий, установщик и сервис координации не создавались. Живые заметки активности предусматриваются отдельными файлами agent/session вне Git.

## Метод

Первому агенту дали только точку входа пакета, временный клиентский каталог и разрешение сохранить там памятку и дополнить стартовый файл. В существующий AGENTS.md заранее помещена контрольная строка для проверки сохранности прежних инструкций.

Второму агенту дали только клиентский каталог, его стартовый AGENTS.md и задачу начать новую сессию. Не передавали первый разговор. Между запусками пакет был закоммичен: содержимое осталось тем же, но изменились SHA и состояние источника DIRTY → CLEAN.

После обнаруженного пробела инструкция уточнена и версия пакета повышена с 2026-09-16.1 до 2026-09-16.2. Третий агент с чистой историей получил тот же клиентский каталог, без подсказки о конкретном исправлении, и должен был восстановить контекст и проверить источник.

## Результаты и отклонения

| Проверка | Результат |
|---|---|
| Сохранение файлов памятки | Пройдено: START, RULES, SERVER, LCT, CHECKLIST, LOCAL, ACTIVITY и SOURCE |
| Сохранность прежних стартовых инструкций | Пройдено: контрольная строка сохранена, указатель добавлен |
| Новый вход без прошлого чата | Пройдено в назначенном клиентском каталоге |
| Понимание проекта и модулей | Верно: вино → запись каталога, стек обсуждается, контракт и независимая проверка обязательны |
| Границы полномочий | Верно: широкая порученная работа ЛЦТ не означает изменение других проектов/служб |
| Чужая активность | Верно: собственный файл, согласование пересечений; старая запись не разрешает убивать процессы |
| Неизвестный сервер | Верно: все агенты отметили блокировку и не выдумали адреса/пути |
| Актуализация происхождения копии | Отклонение во втором запуске: содержимое сверено, но SOURCE остался со старым SHA/DIRTY |
| Повторная проверка после исправления | Пройдено: третий агент обновил весь пакет до .2, сохранил личные дополнения, записал last_verified_at/verified_source_commit/verified_source_state |

Пробел был в инструкции: недостаточно явно требовалось обновлять запись о последней проверке при том же содержимом файлов. В LOCAL.md теперь это отдельное обязательное действие. Исправленная проверенная ревизия пакета: `63fae4e6ff255d222fb66a1199eac1f3c962b73d`.

Основной агент независимо сверил байты шести канонических файлов, каноническую часть LCT.md, все семь SHA-256 в SOURCE, сохранность прежней контрольной строки и личных дополнений. Все проверки прошли.

## Что не проверено

- Реальный SSH-вход друга, его GitHub-доступ, серверные пути, окружение и разрешения общего каталога: сервер не указан.
- Создание заметки на общем сервере и одновременная работа двух реальных аккаунтов: каталога ещё нет.
- Автоматическая загрузка правил конкретным приложением друга: в пробе путь к стартовому файлу задавался явно. Это доказывает восстановление контекста по файлу, но не настройку чужого агента на его компьютере.
- Работа при фактическом конфликте файлов/ресурсов: проверялось понимание правил, не конкурентная нагрузка.
- Постоянное локальное сохранение на компьютере друга: вместо него использован временный клиентский каталог для испытания.

Итог: **пакет и локальный повторный вход проверены; серверный onboarding не завершён**. Для завершения нужны адрес/SSH-псевдоним, отдельный пользователь друга, согласованные каталоги и сведения об агенте друга. Действующее ограничение на постоянные тесты/CI сохранено; его пересмотр отдельно не подтверждён.
