## Метод и границы

Точные дубликаты определены равенством SHA-256 байтов исходного файла. Вероятные визуальные дубликаты определены 64-битным ImageHash `phash` (`hash_size=8`) при расстоянии Хэмминга не более 5. Это только кандидаты на ручную проверку, а не подтверждённые дубликаты.

Использованы Pillow 12.3.0, ImageHash 4.3.2 и Python 3.14.4 в task-local `.venv` (не коммитится).

## Проверка сохранности

После ревизии фактически сверены число и суммарный размер всех исходных регулярных файлов, а также SHA-256 всех 32 325 декодированных изображений: расхождений нет. Повторная проверка хешей выполняется без изменения исходников:

```bash
/srv/lct/work/team-16-4d476db3/.venv/bin/python -c "import hashlib,json; from pathlib import Path; root=Path('/srv/lct/data/roman/vino/2026-09-17/Dataset'); records=(json.loads(line) for line in (root/'91_manifests/audit-2026-09-17-sigma-16-r2/image-manifest.jsonl').read_text().splitlines()); checked=[r for r in records if 'sha256' in r]; actual=lambda p: ((f:=p.open('rb')), hashlib.file_digest(f,'sha256').hexdigest(), f.close())[1]; mismatches=[r['source_file'] for r in checked if actual(root/r['source_file']) != r['sha256']]; print({'hashed_image_files_checked':len(checked),'sha256_mismatches':len(mismatches)}); raise SystemExit(bool(mismatches))"
```
