## Как вести статусы

- **Актуально** — нужно сделать, работа ещё не началась.
- **Предложено** — возможный следующий эксперимент, не запущен; решение после указанных условий.
- **В работе** — есть исполнитель и проверяемый результат.
- **Частично готово** — завершённая часть и оставшийся критерий явно указаны.
- **Проверка** — реализация есть, критерии ещё проверяются.
- **Готово** — критерии выполнены, есть ссылка на результат и ограничения.
- **Отложено** — полезно, но сейчас уступает более важному; указать условие возврата.
- **Заменено** — другой способ или новая информация; указать заменивший пункт/источник.
- **Отменено** — больше не нужно; указать причину и дату.

При каждом изменении: время, прежний → новый статус, причина, доказательство/артефакт.
READY агентом не заменяет независимую проверку. Если осталось время до дедлайна,
берём ближайший подходящий пункт из бэклога после обязательных проверок.

- Лучший проверенный GPU-кандидат B: Top1 44/54, Top5 51/54, Top20 53/54; baseline 42/49/51.
  Постоянный CPU whole-only: 39/50/50 из 54. Это разные профили.

- Исходные 12 ошибок: 5 порядка кандидатов, 4 неверные составные рамки, 2 преждевременных отказа wine gate, 1 выбор соседней бутылки. Повторный разбор уточнил прежнюю группу «9 ошибок ранжирования».
- В отдельном слое100 фото:54 exact,1 подтверждённый out_of_catalog,42 unresolved,3 ambiguous.
- Исходные213 frozen кейсов имеют erratum20 ответов. Исторический v1 и прогоны неизменяемы.
- Лучший self-hosted опыт: RT-DETR R18 + OWLv2 label + SigLIP2 SO400M whole/label + PaddleOCR.
  GPU p95 5,50с в последовательном loopback HTTP. Это не сетевой/нагрузочный SLA.
- TEST: оба endpoint подключены к постоянному CPU whole-only backend. Полная GPU-композиция измеряется отдельно. Demo/PROD не менялись. Original script на Sigma через публичный TEST получил 3/3 допустимых slug; это проверка контракта, не точности и не нагрузочного SLA.
- Без обучения. Сначала исходная конфигурация, затем одна правка, затем комбинации.

## Согласованная граница

Один поисковый механизм, два адаптера:
`/v1/eval/predict` → один slug для оригинального скрипта;
`/v1/search` → ранжированный список идентификационных кандидатов для приложения.
Рекомендации других вин отделены. Не выдаём похожую карточку за доказанное совпадение.
Конкурсный null не объявляем правильным отказом: правила оценки этого случая нет.
Исходный script max-time10с; целевой SLA ТЗ3с. Измерения и гарантии различаем.
