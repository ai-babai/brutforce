# FE-035 · Ревью выдачи фото

Согласованное поведение: [SR-001…009](../../behavior-spec.md#фото-выделенный-лидер-и-вертикальный-список--fe-035).
Источник дизайна: [handoff 1f4855b](https://github.com/ai-babai/brutforce/blob/1f4855b/design/search-results-study/accepted-handoff.md).

21.09.2026, отдельное браузерное ревью локального приложения, Chrome 153.0.8010.50,
viewport 320/390/430 × 844 CSS px, device scale 1. Это не часть быстрого test loop.
React/CSS настоящие, HTTP подменён: пять явно синтетических записей, длинные одинаковые
названия с разными годами, отсутствующее и сломанное фото. Выбранный файл — маленький
синтетический PNG (поэтому preview белый), физическая камера и качество ML не проверялись.

## Проверено

- Размеры: лидер 76×132 px, остальные 56×98 px; object-fit contain.
- Порядок/названия видны; несколько результатов с selectedId не открывают карточку сами.
- После выбора пятого результата и настоящего browser Back scroll восстановлен:
  377 px при ширине 320; 337 px при 390 и 430. Ровно один upload и один search.
- Клавиатура: Tab выбирает следующую строку с именем и годом, видимый фокус
  solid 3 px; Enter открывает карточку, экранная кнопка назад возвращает список.
- Ширина документа равна viewport; горизонтального переполнения карточек нет.
- В отдельной проверке текст всех элементов списка увеличен ровно вдвое от computed
  font-size без изменения ширины контейнера. Это моделирование 200% text-only,
  а не проверка системной настройки каждого мобильного браузера.
- Найдено и исправлено переполнение бейджа лидера на 320 px при 200% текста:
  теперь ограничена ширина, текст переносится; добавлена быстрая SR-009 проверка.

Измерения: [geometry.json](geometry.json). Кадры: [390 px](390.png),
[320 px / текст 200%](320-text-200.png). Длинные экраны прокручиваются вертикально;
полное название не заменяется многоточием.

## Границы

- Реальная мобильная клавиатура, Яндекс/Android и Safari/iOS не проверялись этим запуском.
- Полноценный URL-router/восстановление произвольной истории после reload не добавлены.
  Back карточка → список реализован; Forward после явного ухода нижним меню не
  восстанавливает старую карточку. Это существующее ограничение маршрутизации,
  не обещание браузерной истории для всех экранов.
- Возврат из рекомендации к исходной карточке остаётся отдельным сценарием вне FE-035.
- Код готовится в codex/behavior-demo, этот результат не означает новую публикацию сайта.
