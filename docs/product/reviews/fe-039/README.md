## Исправление масштаба Android (v2)

По фото домашнего экрана Макс выявил чрезмерные поля. Предыдущий тест ошибочно
защищал квадрат фона целиком, а не значимый рисунок. Уточнение дизайна: исходник
83% холста вместо 56%, кремовый круг 70–78% ширины. Системная safe-circle остаётся
радиусом 40%; измеряется светлый/тёплый рисунок, не бордовый градиент фона.
Темные контуры дополнительно проверяются визуально под круглой маской.
Обычные any/Apple/favicon остаются прежними — у них лишнего padding не было.
Новые URL maskable-v2 исключают смешивание версий экспорта.

Maskable v2: оптический сдвиг −1,8% по X, +3,1% по Y; semantic hull согласован с sigma-front.
Декоративный кремовый круг может выходить за safe-circle; бутылка, пёс и лупа — нет.
