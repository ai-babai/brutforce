# Входящие идеи

## 2026-09-19 · первый runnable mobile demo

Пользователь просит первый запускаемый мобильный demo: Go-бэкенд, TypeScript UI,
разрешены явные заглушки. Нужны быстрые исполняемые спеки без браузера в тестовом
цикле, статический отчёт по запускам и честное разделение поведения demo и
качества распознавания.

### Принято в этот инкремент

- Фото этикетки проходит через API к предсказуемой заглушке поиска.
- UI показывает прямой результат, кандидаты и восстановление из ошибок по
  состояниям Wine UX Atlas. Пользовательский путь не содержит панели сценариев,
  banner или слов о прототипе; управление сценариями остаётся только в test/dev
  boundary.
- Проверки фиксируют контракт, переходы состояния и отображаемые данные.
- Отчёт хранит неизменяемые JSON-снимки запусков и показывает изменения по
  ревизиям.

### Не является обещанием

- Заглушка модели не распознаёт вино и не является benchmark.
- Синтетические идентификаторы и записи не являются выгрузкой «Своё Вино».
- Точность, формат `confidence`, таймауты и разрешённые внешние API ждут
  актуального полного ТЗ и оценочного скрипта.
