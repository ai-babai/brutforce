# PWA и короткий экран · 19.09.2026

Сценарии UI-012…015 и DESIGN-010/011 в behavior-spec.md. Установка необязательна, поиск требует сети. Manifest standalone, один маршрут / и API, без offline/cache service worker.

Отдельное браузерное ревью: HTML настоящего экрана камеры выгружен из App с подменой mediaDevices (ожидающий stream), реальные CSS/шрифты; съёмка физической камерой не имитируется как проверенная.
- 390×620: низ затвора612, экран620; высота страницы620.
- 320×480: низ затвора472, экран480; подсказка x89…231 внутри экрана.
- 740×360: затвор147…213, превью8…352, ширина страницы740.
- Найден старый более специфичный селектор .viewfinder span, обрезавший подсказку; новый селектор учитывает каскад, добавлена регрессия.

Фактическая установка и переключение панелей на Android Яндекс Браузере требуют повторной проверки на телефоне. Системный запрос установки тестируется как внешний интерфейс; автоматического полноэкранного режима нет.
Источник решения об install manifest: https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable
