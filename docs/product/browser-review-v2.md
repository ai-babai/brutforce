# Отдельное браузерное ревью v2 · 19.09.2026

Это ручное ревью через браузер, вне быстрого тестового цикла.

- Реальный путь: выбор синтетического PNG → multipart upload → квитанция → поиск → карточка. Байты локального хранилища сверены с исходником.
- Карточка → сравнение с исходником → закрыть → исправить результат → список кандидатов пройдены.
- Главное действие: измеренные CSS размеры иконок 24×24 и 28×28 px, заголовок 30 px.
- На 390 px найден вылет hero на 2 px; исправлены поля. Повторно scrollWidth = viewportWidth.
- Проверены ширины 320, 390, 768 и 1280 px; горизонтального переполнения главного экрана нет.
- Быстрые Design Specs проверяют правила CSS, файлы шрифтов и DOM; они не доказывают пиксельное совпадение всех экранов. Физическая камера телефона и кроссбраузерность остаются отдельным ручным приёмочным шагом.
- Автоопределение бликов, выбор центральной бутылки моделью и настоящее распознавание не реализованы: подсказки UI не являются этими возможностями.
