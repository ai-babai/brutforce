# Независимые проверки Vino

Здесь хранятся компактные QA/verdict-артефакты, связанные с конкретной задачей,
release или экспериментом. Исполнитель продукта не переписывает независимый
verdict в том же проходе.

Минимальный отчёт содержит scope, точные команды/процедуры, фактический вывод,
finding severity, непроверенное и итог `PASS | CONDITIONAL | FAIL`.
