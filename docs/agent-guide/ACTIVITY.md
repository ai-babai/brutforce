# Короткие заметки занятости

Версия пакета: `2026-09-16.3`. Общий каталог определяется в SERVER.md, сейчас не настроен.

На сервере каждый агент обновляет **свой отдельный файл** `<activity-dir>/<agent-id>--<session-id>.md`. ID должны быть уникальными и состоять из безопасных букв/цифр/дефисов. Две сессии одного агента не делят файл. Соседние файлы — для чтения.

Минимальное содержимое:

```text
updated_at: <UTC ISO 8601>
agent: <идентификатор>
session: <уникальная сессия>
module: <модуль или docs>
workspace: <проверенный абсолютный путь>
branch: <фактическая ветка или n/a>
status: working | done | blocked
note: <одна короткая строка; без секретов>
```

Прочитай каталог перед работой. Для пересекающихся задач сначала договорись о разделении. Публикуй собственный файл через временный файл в той же папке и rename; это уменьшает риск чтения наполовину записанного текста. Не перезаписывай существующий чужой файл при коллизии ID.

Обновляй при старте, смене области и завершении/блокировке. Постоянный heartbeat не нужен. Старая запись — повод уточнить состояние, не разрешение забрать GPU, остановить процесс или удалить работу. Файл не является lock-механизмом.

Живые заметки лежат вне Git-копий проекта. Не добавляй их в коммиты. Права общего каталога проверяются под собственными аккаунтами участников; не исправляй доступ командой chmod 777.
