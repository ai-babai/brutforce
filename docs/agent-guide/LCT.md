- Репозиторий: https://github.com/ai-babai/brutforce — приватный.

## Локальные поля участника

Заполняются в личной копии этого файла после проверки, без изменения общего документа:

- agent_id: UNCONFIGURED
- собственная рабочая копия: UNCONFIGURED
- ветка: UNCONFIGURED
- текущая задача/модуль: UNASSIGNED
- папка активности: из проверенного SERVER.md
- место хранения локальной памятки: фактический путь
- стартовый файл агента с указателем на памятку: фактический путь либо NOT_INSTALLED

Не записывай задачу как выполненную и не заполняй неизвестные поля правдоподобными предположениями.
