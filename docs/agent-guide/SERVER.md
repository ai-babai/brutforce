Сначала прочитай `/srv/AGENTS.md`. Обычные процессы `lct` не идут автоматически через NL;
интеграция с подготовленным туннелем — отдельная задача. Рабочая копия на Mac не является серверной папкой.

Используй только свой разрешённый SSH-ключ. Перед изменением проверь hostname, whoami, путь,
свободное место, remote, ветку и git status. Не печатай секреты. Не запускай службы и не устанавливай
ПО только из-за знакомства с сервером.

Зона Романа — `/srv/lct/roman`; не сбрасывай общую копию или чужую зону. Для БД не дублируй команды
из памяти: прочитай [DATABASE.md](DATABASE.md) и её операционный runbook.

Исходник пакета — приватный Git-репозиторий. Серверная копия содержит `SOURCE.md` с хешами и ревизией;
локальные правки до commit/push помечаются `DIRTY`. Доступы к GitHub и SSH, установка ПО и серверные
изменения выполняются только по конкретной задаче владельца.

GitHub использует отдельный серверный ключ `/home/lct/.ssh/github_brutforce` с записью только в BrutForce.
Не копируй его участникам. Для правок создавай отдельные ветки и worktree в `/srv/lct/work`;
основную копию не используй одновременно несколькими агентами.
