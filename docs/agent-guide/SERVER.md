Сначала прочитайте /srv/AGENTS.md. Обычные процессы lct НЕ автоматически идут через NL;
интеграция приложений с подготовленным туннелем отдельная задача.
Рабочая копия на Mac /Users/skif/develop/brutforce не является серверной папкой.

Используйте только свой разрешённый SSH-доступ. До добавления ключа не заявляйте
готовность личного подключения. Администратор может проверить права через sudo -iu lct;
это не выдаёт участнику административных полномочий.
При входе наблюдательно проверьте hostname, whoami, пути, свободное место,
Git remote/status/branch в существующей копии. Не печатайте секреты.
Отсутствующие приложения не устанавливаются автоматически в рамках знакомства.

Исходник пакета — приватный Git-репозиторий. Установленная серверная копия содержит
SOURCE.md с хешами и ревизией; локальные правки до commit/push помечаются DIRTY.
Доступы к GitHub и SSH, установка ПО и серверные изменения выполняются в рамках
конкретного задания владельца, а не по факту чтения этой инструкции.

GitHub: отдельный ключ сервера /home/lct/.ssh/github_brutforce с записью только в BrutForce. Не копировать его участникам. Для задач создавайте отдельные ветки и worktree под /srv/lct/work; основную копию не используйте одновременно несколькими агентами для правок. Версию установленного пакета /srv/lct/guide сверяйте по SOURCE.md.
