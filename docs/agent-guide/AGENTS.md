# Вход в BrutForce

Версия пакета: `2026-09-20.1`. Пакет предназначен участнику и его агенту; история чата не требуется.

1. Прочитай [RULES.md](RULES.md), [SERVER.md](SERVER.md), [LCT.md](LCT.md) и [BOARD.md](BOARD.md).
2. Для работы с БД прочитай [DATABASE.md](DATABASE.md), затем выполни [CHECKLIST.md](CHECKLIST.md).
3. Сохрани локальную памятку по [LOCAL.md](LOCAL.md).
4. Веди короткую заметку по [ACTIVITY.md](ACTIVITY.md), когда серверный каталог определён и доступен.

Если SERVER.md содержит `UNCONFIGURED`, не угадывай адрес, пользователя или пути.
Можно читать пакет и сохранить памятку; серверные изменения ждут уточнения полей.
Незавершённый onboarding не запрещает остальную работу: перечисли конкретные недостающие сведения.

Пакет: <https://github.com/ai-babai/brutforce/tree/main/docs/agent-guide>.
Для чтения нужен разрешённый доступ; ссылка не выдаёт GitHub- или SSH-доступ.

Первичное подключение включает чтение, проверки и локальную памятку.
Оно не заменяет отдельную задачу реализации, установки ПО, загрузки моделей или изменения служб.

Для передачи агенту достаточно:

> Прочитай `docs/agent-guide/AGENTS.md` в BrutForce. Пройди первичное подключение,
> сохрани памятку и подключи её к своим стартовым инструкциям. Сохрани существующие
> инструкции. Сообщи готовность и препятствия; продукт без отдельной задачи не разрабатывай.
