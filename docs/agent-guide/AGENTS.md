# Вход в BrutForce

Версия пакета: `2026-09-16.1`. Этот пакет предназначен для другого участника и его агента; история переписки с владельцем не требуется.

1. Прочитай [RULES.md](RULES.md), [SERVER.md](SERVER.md), [LCT.md](LCT.md).
2. Выполни [CHECKLIST.md](CHECKLIST.md) для первого или повторного входа.
3. Сохрани локальную памятку по [LOCAL.md](LOCAL.md).
4. Веди короткую заметку по [ACTIVITY.md](ACTIVITY.md), когда серверный каталог определён и доступен.

Если SERVER.md содержит `UNCONFIGURED`, не угадывай адрес, пользователя и пути. Можно прочитать пакет и сохранить локальную памятку; подключение и серверные изменения заблокированы до уточнения соответствующих полей. Незавершённый onboarding не равен запрету на всю дальнейшую работу: перечисли конкретно недостающие сведения.

Пакет хранится в приватном репозитории https://github.com/ai-babai/brutforce/tree/main/docs/agent-guide. Для чтения нужен собственный разрешённый доступ к репозиторию. Ссылка не выдаёт SSH-доступ или GitHub-доступ.

Первичное подключение включает чтение, проверки и локальную памятку. Не начинай реализацию продукта, установку ПО, загрузку моделей или изменение служб, если текущая задача этого не требует.

Для передачи агенту достаточно:

> Прочитай docs/agent-guide/AGENTS.md из репозитория BrutForce. Выполни первичное подключение, сохрани памятку и подключи её к своим стартовым инструкциям. Сохрани существующие инструкции. Сообщи готовность и препятствия; продукт пока не разрабатывай.
