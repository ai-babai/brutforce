# Синтетический каталог и сохранённое

Производитель: Go API; потребитель: React UI. Каноническая база прототипа — `apps/api/catalog.json`, встраиваемая в бинарник. Это небольшой read-only JSON-каталог, без внешней СУБД. Поля записи соответствуют `demo-search.schema.json`.

`GET /api/catalog` → `{ "demo": true, "candidates": [...] }` без selectedId. ID уникальны и совпадают с результатами POST /api/search. Название, винодельня, год, описание и иллюстрация одной карточки не меняются при переходе между поиском и сохранённым. Записи и новые иллюстрации синтетические; настоящие каталожные факты и качество поиска не заявляются. Вкладка «Источник» сохраняет маркировку происхождения.

Сохранённое — локальный список снимков карточек в браузере. Сохраняется после перезагрузки на этом устройстве, не синхронизируется между людьми/браузерами. Фото пользователя не копируются в этот список. Удаление записи не удаляет оригиналы фото на сервере. При запрете записи storage интерфейс сообщает, что постоянное сохранение не удалось. Повреждённая запись не должна ломать запуск приложения.

Установка PWA не обязательна. Поиск/каталог используют тот же API в обоих режимах. Offline-каталог, общий аккаунт и совместное избранное вне текущего объёма.
