## От свободной идеи к проверяемому поведению

Пользователь открывает каталог на телефоне, ищет вино, рассматривает бутылку и
проверяет происхождение сведений. Ему не нужны 2038 загрузки сразу или выдуманные поля.
Первая страница — 24 записи, максимум API — 60; «Показать ещё» продолжает ту же выборку.
Изображения — файлы, мета и ссылки — БД. Модель распознавания остаётся заглушкой.
Каталог и ручной поиск используют `/v2/catalog`; детали — `/v2/catalog/{slug}`.
Миграция major-версии описана в [правилах версий](../../contracts/api-versioning.md#be-045--каталог-v2).

| ID | Дано | Когда | Тогда |
|---|---|---|---|
| CAT-001 | 2038 канонических вин в одной версии | Пользователь открывает каталог и последовательно листает | Первая выдача не больше 24; стабильный порядок slug, каждый ID ровно один раз; последняя страница без nextCursor; неверный cursor даёт 400, устаревшая версия — 409 |
| CAT-002 | Искомое вино находится за первой страницей | Пользователь отправляет название, винодельню или год с любого входа в ручной поиск | Сервер ищет по всему каталогу; новый запрос сбрасывает cursor; старый ответ не заменяет и не дополняет новую выдачу; пустой результат и ошибка с повтором различимы |
| CAT-003 | Узкие бутылки и варианты thumbnail/card/original разных размеров | Открываются список и карточка на разных DPR | srcset содержит фактические width; браузер выбирает подходящий вариант; фиксированная область contain; изображения ниже первого экрана отложены; отсутствующее/повреждённое фото даёт fallback |
| CAT-004 | Год/объём неизвестны, крепость невалидна либо задана диапазоном | Поля сериализуются и открывается карточка | Неизвестные поля отсутствуют в API; UI не показывает 0/NaN/выдуманные факты; для года допустимо «Год не указан»; валидный диапазон сохраняется без превращения в точное число |
| CAT-005 | Три описанные спорные карточки из #44 | Импортируются и показываются разрешённые характеристики | Abrau/СКБ без category/color, sweetness сохранён; ESSE без category/sweetness, цвет сохранён; сырая «Категория и цвет» не просачивается, догадки не добавлены |
| CAT-006 | Три aliases указывают на существующие canonical ID | Открывается старый slug, список или поиск | Детали содержат canonical ID; aliases не самостоятельные позиции; отсутствующий slug даёт JSON 404 |
| CAT-007 | Настоящая карточка и reference-модель имеют независимое происхождение | Пользователь открывает источник карточки или результат reference-поиска | Настоящие URL/дата сохранены; карточка не названа синтетической; reference-распознавание явно обозначено как заглушка; несовместимость версий даёт ошибку, а не выдуманный результат |
| CAT-008 | В БД каталог A, подготовлен пакет B | Выполняется dry-run, импорт с ошибкой, успешный импорт, повтор и восстановление | Dry-run/ошибка не меняют A; B импортируется атомарно; повтор B идемпотентен; A восстанавливается из snapshot без reset |
| CAT-009 | Импортирован каталог с неизвестным годом и aliases | Повторно запускаются миграции/seed | SQL NULL года, данные и aliases сохранены; synthetic seed не добавляет лишние товары |

## Конкретные проверочные примеры

1. **CAT-001.** Быстрый набор содержит 73 синтетических canonical ID и aliases.
   Без limit возвращаются 24 записи; полный обход возвращает все 73 ровно один
   раз в порядке slug. Запрос limit=60 ограничен 60; 0, 61 и нечисловое значение
   дают 400. Cursor другого q даёт 400, другой версии — 409.
2. **CAT-002.** Запись за первой страницей находится и через «По названию»
   с главной, и после «Открыть каталог». Оба пути вызывают GET с q.
   При смене q во время загрузки следующей страницы прежний запрос отменяется;
   его поздний ответ игнорируется. Повтор ошибки сохраняет q, пустая выдача
   не показывается как сетевой сбой. Лупа и Enter имеют одинаковое действие.
3. **CAT-004/005.** Отдельные минимальные синтетические записи содержат
   отсутствующие год/объём, невалидную крепость, валидный диапазон крепости
   и каждую из трёх спорных проекций. Ожидаемые разрешённые поля задаются
   из требования; сравнение не вычисляет их тем же mapper, который проверяется.
4. **CAT-006.** Проверяются все три aliases и отсутствие их ID в списке/поиске.
   HTTP-тест с подменённым store проверяет форму ответа; PostgreSQL-тест
   отдельно подтверждает реальное разрешение сохранённых aliases.
5. **CAT-007.** Компонент получает допустимый reference-ответ с настоящей
   карточкой: source URL/дата видны, заглушка распознавания обозначена,
   утверждения «карточки синтетические» нет. Это проверка UI-границы.
   Реальный несовместимый reference-сервис возвращает явную ошибку;
   этот пример не требует успешного распознавания отсутствующей моделью.
6. **CAT-008/009.** Полный snapshot A сравнивается после dry-run B,
   ошибки валидации B и ошибки после начала записи B. Успех B и повтор B
   дают одинаковое содержимое; seed/migration сохраняют B, SQL NULL и aliases.
   Restore A проверяется повторным чтением, а не только отсутствием ошибки.
   Невалидные path/hash/dimensions/type/bytes/aliases отклоняются до мутации.
   Symlink направлен на существующий валидный файл: ошибка не может быть
   следствием отсутствующего target. Каждый negative fixture валиден
   по остальным условиям до внесения проверяемого повреждения.
7. **REPORT-004.** Когда Go-проверка сценария падает, а UI-проверка того же ID
   проходит, итог сценария failed и сохраняет оба свидетельства. Два ID
   в имени теста учитываются оба. Незапущенные уровни проверки не становятся
   пройденными из-за успешного другого уровня.
8. **CAT-003/SR-009.** В браузере проверяются 320/390/desktop, DPR 1/2/3,
   увеличенный текст, currentSrc и сетевые запросы изображений, contain,
   отсутствие горизонтального переполнения, фокус и отложенная загрузка.
   Быстрые DOM-assertions проверяют атрибуты, выбор карточки и fallback.

## Уровни проверки

| Уровень | Что доказывает | Что остаётся за границей |
|---|---|---|
| Быстрый Go/React | Валидация, HTTP-форма, DOM-атрибуты, состояния и переходы; маленькие синтетические записи | Mock store не доказывает PostgreSQL; mock HTTP не доказывает работающий backend; jsdom/CSS substring не доказывают геометрию |
| PostgreSQL интеграция | Транзакции, NULL, aliases, seed, повтор импорта и restore на отдельной тестовой БД | Не подтверждает импорт в постоянную БД и работу опубликованного сайта |
| Офлайн dry-run полного пакета | Валидация фактического пакета v2 без мутации БД | Не подтверждает транзакцию, browser UX или ML-качество |
| Браузер | Геометрия, currentSrc/network, DPR, lazy, клавиатура и настоящий History Back | Не подтверждает качество распознавания |

Длительности быстрых проверок фиксирует существующий runner. Свидетельства
уровней записываются отдельно. Успех только быстрых тестов означает именно
успех быстрых тестов; незапущенный браузер или PostgreSQL остаются незапущенными.

## Границы

Полная истинность источника/MLкачество не проверяются этой задачей. Не парсим год
из названия. Не публикуем датасет вGit. Не импортируем постояннуюБД/не выкатываем
сайт автоматически. Общий TEST/PROD проходят deploy/PIPELINE.md отдельным поручением.
