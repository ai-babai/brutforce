# Передача распарсенного Dataset

Этот data-only пакет предназначен для внутренней передачи команде BrutForce.
Он содержит нормализованные наборы `01`–`18`, таблицы, разметку, изображения,
review queues, splits-контур, manifests и отчёты.

## Состав

- `Dataset/01_...18_.../**`; воспроизводимые `cache/` исключены, кроме файлов,
  на которые напрямую ссылаются media-таблицы и без которых пути были бы битыми;
- каталожные изображения и detection/label-element corpora из `media/`;
- только те файлы из `Dataset/00_raw/**`, на которые непосредственно ссылаются
  нормализованные media/PDF-таблицы;
- `Dataset/90_splits`, `91_manifests`, `92_reports`, `99_quarantine`;
- dataset contracts, registry и правила review/annotation.

## Не включено

- исходные архивы, полные HTML-captures, sitemap/robots snapshots и иные
  нереференсные raw-файлы;
- проектный код, Agents OS, исходное PDF-ТЗ и инфраструктурные инструкции;
- секреты, ключи, токены, веса и векторные индексы.

Пути зависимостей сохраняются с корнем `Dataset/`, поэтому таблицы можно читать
без переписывания `relative_path`. `PACKAGE-MANIFEST.jsonl` и
`PACKAGE-SUMMARY.json` находятся в `Dataset/91_manifests/`.

Пакет не является frozen training release: review queues не закрыты, а
`train/val/test` ещё не зафиксированы. `rights_status` и ограничения каждого
источника продолжают действовать; пакет нельзя публиковать или передавать вне
команды без отдельной проверки прав.
