# 07 — X-Wines

Кандидат для metadata/recommendation исследований и пилота по изображениям
этикеток; не основной источник field-query. Полная версия заявляет 100 646 вин
и 21 013 536 рейтингов из 62 стран.

Статус: GitHub Test 100 и Kaggle Slim 1K приняты и проаудированы. В Slim — 1 007
товаров и 1 007 декодируемых image-level WineID labels, включая 7 российских.
Визуальный crosswalk с текущим «Своим Вином» выполнен для всех семи: три связи
только уровня product line/другой винтаж, exact cross-source SKU merges — 0.
Лицензия и citation фиксируются отдельно для каждой edition.
