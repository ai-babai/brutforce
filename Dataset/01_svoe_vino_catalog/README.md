# 01 — каталог «Своё Вино»

Источник: `caseholder-svoe-vino-2026-09` в `../REGISTRY.yaml`. Raw-архив не
распаковывается сюда вручную: каталог строится воспроизводимым pipeline.

Итоговый аудит: 4 147 строк CSV, 2 103 уникальных slug и 15 770 изображений с
вариантами Strapi. Из них 5 487 имеют exact asset-key label, 61 неоднозначны,
10 222 относятся к site assets вне продуктового контура; один файл не
декодируется и исключён. Внутри также есть три evaluation query без открытых
ответов — они получают роль `caseholder_eval` и не участвуют в training/tuning.

Воспроизводимые выходы находятся в `tables/`; exact duplicates, reused
filenames, отсутствующие и неоднозначные связи сохраняются явно. Frozen split
ещё не назначен.
