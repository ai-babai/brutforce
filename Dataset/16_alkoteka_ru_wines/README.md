# 16_alkoteka_ru_wines

Версионированный snapshot российских вин [Алкотеки](https://alkoteka.com/catalog/)
на 2026-09-15 для фиксированного контекста города Краснодар.

- `source_id`: `alkoteka-russian-wine-web-2026-09-15-krasnodar`;
- `source_capture_id`: `capture_alkoteka_517d4364d655df114754`;
- публичные категории: `vino` (551) и `shampanskoe-i-igristoe` (176);
- 727 уникальных source SKU, 727 карточек и 727 скачанных оригинальных файлов;
- у всех карточек есть явные `country_code=RU`, `country_name=Россия` и значение
  «Россия» в характеристиках;
- все 727 файлов декодируются и имеют SHA-256/dHash;
- 663 связи product/media пригодны для identity-supervision по автоматическим
  проверкам; право на обучение остаётся закрыто до проверки условий источника;
- 53 SKU используют один общий placeholder и исключены, ещё 11 SKU в пяти
  группах делят одинаковые реальные изображения и ждут identity-review;
- API карточки публикует только один `image_url`: дополнительных gallery-полей
  в 727 сохранённых ответах не обнаружено;
- связь со snapshot «Своё Вино» не выполнялась, `svoe_vino_slug=null`.

Сырые ответы и изображения находятся в
`Dataset/00_raw/16_alkoteka_ru_wines/2026-09-15/`, нормализованные таблицы — в
`tables/`, очереди проверки — в `review/`. Чистые каталожные изображения не
требуют bbox; `needs_annotation` поэтому пуст, а нерешённые identity/image
случаи направлены в `needs_verification` без физического перемещения файлов.

Повторяемый сбор:

```powershell
python scripts/dataset/crawl_alkoteka.py --capture-date 2026-09-15
```

Скрипт использует один честный User-Agent, последовательные запросы с паузой,
учитывает `robots.txt` и немедленно останавливается на HTTP 403/429 или
подтверждённом challenge. Ротация заголовков, cookies, IP и обход ограничений не
используются.
