# 03 — ручная съёмка в магазинах

Будущий first-party набор реальных полочных условий. Для каждой сессии нужны:
`capture_id`, дата/место на согласованном уровне точности, автор/согласие,
устройство, условия съёмки, видимые товары, проверенный `product_id`/`slug` и
права на обучение/публикацию.

Сырые сессии кладутся без переименования в
`Dataset/00_raw/03_manual_store/incoming/<capture_session_id>/`. После приёмки
заполняются шаблоны из `schemas/`; производные изображения и аннотации не
перезаписывают оригиналы.

Обязательные сценарии: фронтальная этикетка, угол, блики, размытие, occlusion,
дальняя полка, несколько бутылок и unknown wine. Сначала резервируется holdout
по магазину/сессии/identity, затем training; серийные кадры не пересекают splits.

Перед включением кадра обязательны: успешный decode, SHA-256, отсутствие лиц и
номеров телефонов либо их отдельная privacy-обработка, разрешение на съёмку,
проверенный SKU каждой размеченной бутылки и bbox в пиксельных координатах.
