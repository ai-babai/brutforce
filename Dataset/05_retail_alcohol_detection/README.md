# 05 — Retail Alcohol Detection Dataset

Кандидат высокого приоритета для адаптации к российским полкам: clutter,
перекрытия, ценники, разные углы и свет. Это вспомогательный detection/domain
набор, а не источник точных slug «Своё Вино».

Статус: скачан, безопасно распакован и проаудирован. Все 1 884 изображения
декодируются; 21 441 YOLO bbox имеет существующее изображение, class label и
валидную геометрию. Exact Russian wine SKU labels отсутствуют. Заявленная
лицензия — MIT.
