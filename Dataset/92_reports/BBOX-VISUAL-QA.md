# Визуальная QA боксов — 2026-09-15

Геометрия и ссылочная целостность проверены для всех боксов автоматически:
каждый bbox имеет существующий `media_id`, непустой class label и координаты в
границах изображения (с допустимой epsilon-коррекцией округления YOLO).

Дополнительно выполнена воспроизводимая визуальная spot-check проверка скриптом
`scripts/dataset/render_bbox_audit_samples.py`:

- Retail Alcohol Detection: 12 кадров, равномерно выбранных по отсортированному
  detection manifest. Боксы визуально покрывают отдельные бутылки/алкогольные
  товары; систематического сдвига координат или перепутанной системы координат
  не обнаружено.
- RF100 Wine Labels: 12 разных изображений — по одному представителю для каждой
  категории, реально встречающейся в bbox-аннотациях (12 из 13 объявленных
  категорий). Боксы находятся на соответствующих текстовых/логотипных элементах.
  В upstream-разметке есть ожидаемая семантическая неоднородность и мелкие
  спорные области, поэтому RF100 используется только как auxiliary
  label-element detector, не как SKU ground truth.

Это выборочная проверка семантики, а не ручной просмотр всех 46 475 боксов.
Полная проверка всех записей покрывает геометрию, class label и referential
integrity; смысловая корректность всех боксов остаётся ответственностью upstream.
