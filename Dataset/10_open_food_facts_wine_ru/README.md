# 10 — Open Food Facts: российские вина

Приоритетный открытый источник для точечного пополнения. Сначала загружается и
фильтруется структурированная metadata по категории wine, стране/рынку и
производителю; только затем выбираются нужные изображения из открытого S3.
Полный image bucket не скачивается.

Статус: metadata-снимок скачан и профильтрован. Из 28 первичных кандидатов
отклонены 8 импортных и 3 ошибочно категоризированных товара; у 13 российских
brand/probable candidates найдено 11 front-изображений, все декодируются и
привязаны к exact barcode records. Проверка российского происхождения остаётся
ручным gate. База и изображения имеют разные условия
(ODbL и CC BY-SA); для каждого объекта сохраняются product code, source URL,
лицензия, авторство/атрибуция и capture timestamp. Exact соответствие каталогу
«Своё Вино» подтверждается отдельно.
