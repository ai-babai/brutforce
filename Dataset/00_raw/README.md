# 00_raw — неизменяемые источники

Здесь лежат только полученные исходные байты. После приёма файл не изменяется и
не переименовывается. Его SHA-256 фиксируется в `../91_manifests/` и реестре.

Полученные snapshots находятся в каталогах `01`, `02`, `04`–`17`; `03` оставлен
для будущей ручной магазинной съёмки. Для web-sources raw включает policy/
sitemap, ответы карточек/API и оригинальные разрешённые изображения либо
зафиксированный HTTP blocked-state. Любая распаковка и нормализация выполняется
в соответствующем нумерованном производном каталоге, не поверх `00_raw`.

Сырые файлы исключены из Git. Публикация, синхронизация и удаление требуют
отдельного решения по конкретному источнику.
