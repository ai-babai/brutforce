# 06 — Wine Images Dataset 126K

Кандидат для общего image-text/bottle pretraining на чистых товарных фото.
Заявлено 107 821 изображение и связь с текстовыми метаданными, CC BY 4.0.

Статус: companion text metadata скачана; 125 787 строк отфильтрованы по регионам
и известным российским брендам. Российских кандидатов — 0, поэтому image shards
не скачивались. Лицензия компиляции не снимает вопрос прав на исходные retailer
photos, поэтому публикация производных требует отдельной проверки.
