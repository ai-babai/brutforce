# Значимые проходы и эксперименты

Один каталог на проход: `YYYY-MM-DD-<task-or-short-name>/`.

Минимум: `REPORT.md`, точный scope, входные версии/хеши, команды и результат,
непроверенное, ограничения и один следующий шаг. Тяжёлые веса, индексы и
изображения остаются вне Git и адресуются безопасным manifest ID.
