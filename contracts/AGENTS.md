# Контракты

Наследуй [../AGENTS.md](../AGENTS.md). Здесь описываются границы модулей и канонические схемы.
Не придумывай поля каталога и требования API до изучения данных; черновик помечай предложением.
При изменении схемы укажи производителей и потребителей и обнови их одной согласованной работой.
Примеры содержат синтетические или разрешённые публичные данные; секреты и реальные фото не попадают сюда.
