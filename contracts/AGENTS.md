# Контракты

Наследуй ../AGENTS.md. Эта область описывает границы модулей и канонические схемы обмена.
Не придумывай поля каталога и требования API до изучения данных. Черновик явно помечай как предложенный.
При изменении схемы укажи производителей и потребителей и обнови их в одной согласованной работе.
Примеры содержат только синтетические или разрешённые публичные данные. Секреты и реальные фото сюда не попадают.
