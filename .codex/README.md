# Codex в Vino

Долговременные проектные правила находятся в корневом `AGENTS.md`, который
Codex загружает автоматически. `config.toml` не закрепляет модель, sandbox,
approvals, provider или web search: эти параметры наследуются из текущей
пользовательской/desktop-среды и не должны ломать активную сессию.

Проектные custom agents находятся в `agents/`. Каждый профиль узкий, имеет
описанную зону и не расширяет разрешения на внешние действия. Их следует
использовать только при явной просьбе пользователя о делегировании или когда
применимая проектная инструкция прямо требует параллельной работы.

Project skills и MCP пока не добавлены: сначала должен появиться повторяемый
workflow либо фактическая внешняя система, для которой это оправдано.
