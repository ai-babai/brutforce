# Роман и его агент: начать здесь

Актуально: 2026-09-21. Это короткий маршрут, подробные правила — по ссылкам.

## Сначала

1. Прочитай [AGENTS.md](AGENTS.md), [MAP.md](MAP.md) и [правила команды](docs/agent-guide/RULES.md).
2. На сервере прочитай `/srv/AGENTS.md` и `/srv/lct/AGENTS.md`; затем правила своей рабочей копии.
3. Открой [SERVER.md](docs/agent-guide/SERVER.md) и [CHECKLIST.md](docs/agent-guide/CHECKLIST.md).
4. Сохрани локальную памятку по [LOCAL.md](docs/agent-guide/LOCAL.md) и ссылку на этот вход.
   Существующие стартовые инструкции не перезаписывай. Следующая сессия должна найти памятку без этого чата.

## Как брать и завершать задачу

- [Доска](https://github.com/users/ai-babai/projects/2) и [BOARD.md](docs/agent-guide/BOARD.md).
- Сначала найди дубликат, запиши инициатора Романа, область, исполнителя и свою сессию/ветку.
- Для своей работы выбирай «Агент-Ромы»; «Команда Sigma» запускает другой поток, не ставь его случайно.
- Стартовый чек-лист: [INFRA-007](https://github.com/ai-babai/brutforce/issues/7).
  Проверь прошлые результаты; создай одну полезную/учебную карточку только если ещё не создана.
- Закончив работу, приложи результат и проверки. Обычная задача идёт в Human verification; Done — после приёмки.
  Учебный onboarding закрывай по явным критериям CHECKLIST.md; не отмечай непроверенные пункты.
- Если застрял: Pending, понятное русское резюме «что случилось / что успел / что осталось / какая помощь нужна».
  Приложи issue/PR и точную ссылку на сессию OpenCode, если работал в нём. Не запускай скрытые повторы.
- Действуя именно от имени Sigma, используй aika-ai-agent и `/srv/agents/sigma/TEAM.md`;
  личную работу Романа не подменяй этой учётной записью.

## Если агент запущен на Windows

Используй OpenSSH из PowerShell и свой уже настроенный ключ. Bash-команды из серверных инструкций
выполняются **после входа по SSH**, не напрямую в PowerShell. Ключи и пароли здесь не хранятся.

Инструкции меняются вместе с работой: обнови канонический файл в Git и серверную копию, не плодя памятки.
Новый раздел заводи по реальной необходимости. Лимиты коротких инструкций — в AGENTS.md.
