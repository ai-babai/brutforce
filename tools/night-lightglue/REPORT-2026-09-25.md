# DISK + LightGlue on fixed B Top20 — night experiment

**Result:** do not select this reranker. The full frozen and organizer runs
regressed against B, including a conservative follow-up gate. The experiment
used pretrained weights only, with no model training. These are diagnostics on
the existing development inputs, not an independent holdout.

## Architecture

```text
full-frame service / verified retrieval crop
  → unchanged B: RT-DETR + Base224 gate + SO400M whole/label + OCR
  → unchanged B Top20 and selected target/label-context box
  → DISK(depth, 1024 keypoints) on query label and SHA-verified references
  → LightGlue(disk) on each of the 20 pairs
  → RANSAC homography: inliers × sqrt(query coverage)
  ├─ pure geometry rerank; B rank breaks ties
  └─ fixed 50/50 B-rank/geometry-rank fusion
  → one catalog slug, or B's original action when it had no pool
```

The reference DISK features were precomputed once. Missing and quarantined B
reference rows were not substituted; the 20 candidates stayed fixed. The query
runner received no answers. It extracted query features afresh for each request,
including duplicate organizer files. A match needed at least 8 homography
inliers and 2% coverage of the query label crop. The first full frozen result
was scored before adding the separate conservative cascade below.

## Quality

| Variant | Frozen service pass / 141 | Frozen retrieval Top1/5/20 / 62 | Organizer exact Top1/5/20 / 54 |
| --- | ---: | ---: | ---: |
| B control | **114** | **57 / 59 / 62** | **44 / 51 / 53** |
| Pure geometry | 73 | 33 / 62 / 62 | 29 / 47 / 53 |
| Fixed 50/50 fusion | 97 | 49 / 61 / 62 | 37 / 50 / 53 |
| Conservative cascade* | 110 | 57 / 59 / 62 | 43 / 51 / 53 |

The frozen suite contains 213 cases: 151 service (141 graded, 10 ungraded)
and 62 retrieval. Organizer inputs contain 103 files with 100 unique image
hashes. The corrected internal diagnostic labels classify those 100 as 54 exact,
42 catalog-unresolved, 3 ambiguous, and 1 reviewed out-of-catalog. The latter
was still returned as a catalog card by every variant (0/1 correct refusal).
The unresolved and ambiguous images are outside the exact denominator.

Pure geometry fixed 2 graded frozen service cases and broke 43; fusion fixed 2
and broke 19. On frozen retrieval, neither fixed a B Top1 error; they broke 24
and 8 respectively. On 54 unique organizer exact images, pure geometry fixed 3
and broke 18; fusion fixed 3 and broke 10. These changes show that strong local
correspondence is often evidence for the wrong catalog slug or wrong selected
physical target, particularly with related label layouts. Exact repeated
reference images across catalog slugs are another ambiguity that geometry alone
cannot resolve.

*The cascade was defined **after** reviewing the initial negative frozen score,
so its same-suite number is exploratory. It keeps B unless a unique-reference
candidate in B ranks 2–5 has ≥50 inliers, ≥10% coverage, and ≥2× B Top1's
geometry score. It changed 6 frozen and 8 organizer requests, with 1 fix and
5 breaks in graded frozen service, no retrieval Top1 change, and 1 fix / 2
breaks among unique organizer exact images. No further threshold tuning was
performed.

## Coverage and runtime

The B catalog contains 2,103 rows. Its gate-v2 index marks 2,060 available;
all 2,060 exact source bytes were recovered and SHA-verified. DISK extraction
precomputed those 2,060 rows in 182.1 seconds on an NVIDIA L4, excluding model
load. The feature files total about 1.1 GiB. Twenty candidate comparisons were
attempted per nonempty B pool. There were 3,700 frozen and 2,060 organizer
candidate pairs; 45 and 29 lacked a gate-valid reference because B can include
OCR-only candidates. The matcher returned no pair errors. Frozen service had 28
queries with no B candidates, and their original action was preserved.

| Increment on NVIDIA L4, no B inference | p50 | p95 | p99 | max | >3 s | >10 s |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Frozen 213 | 0.825 s | 2.248 s | 2.983 s | 3.218 s | 2 | 0 |
| Organizer 103 | 1.820 s | 2.944 s | 3.153 s | 3.168 s | 2 | 0 |

The incremental times include query cropping, DISK extraction, feature-cache
reads, 20 LightGlue matches, and geometry/reranking. They exclude B inference,
HTTP upload and network transit. A warm checkpoint-cache process loaded both
models in 8.8–11.0 seconds. Observed GPU process memory during matching was
about 5.2 GiB. The complete B+LightGlue endpoint was not benchmarked under
the original 10-second HTTP script, so these results establish no end-to-end
SLA. Summing historical B latency and current rerank time is only a modeled
diagnostic across different GPUs.

weights, and DISK. This experiment did not use SuperPoint. The useful part of
the approach is precise visual correspondence when a query and a verified
reference depict the same physical label. Its failure here is ranking reliability
and added latency on this exact-catalog task. The best measured decision is to
retain B and pursue better target selection and text/identity evidence instead.
