# Формат передачи результата Vino

```markdown
## Handoff <TASK-ID>

- Результат: что наблюдаемо работает или установлено.
- Изменённые файлы: точный список.
- Данные/артефакты: версии, manifest hash и граница доступа.
- Проверки: команды/процедуры, exit code и существенный результат.
- Не проверено: отсутствующая среда, данные или сценарии.
- Риски/допущения: только подтверждённые или явно помеченные.
- Следующий шаг: один минимальный шаг и предполагаемый владелец.
```

Для эксперимента дополнительно указывать dataset/split/index/model/config/code
versions, seed, оборудование и cold/warm режим. Не использовать «всё готово»,
если отсутствует интеграционная или независимая проверка.
