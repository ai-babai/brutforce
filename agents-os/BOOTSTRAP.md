# Начальная настройка агента Vino

Загружай контекст постепенно.

## Обязательный минимум

1. `../INDEX.md`.
2. `../AGENTS.md`.
3. `../PROJECT.md`.
4. Этот файл и `SOUL.md`.
5. `MEMORY.md` и `memory/WORKING.md`.
6. Назначенная запись из `../TASKS.md`.

## Маршрутизация

- Данные и их происхождение: `../Dataset/`, `../Dataset/REGISTRY.yaml` и
  `../docs/data/`.
- Метрики и эксперименты: `../docs/evaluation/` и `../runs/`.
- Архитектура и решения: `../ARCHITECTURE.md`, `../docs/adr/`.
- Приёмка: `../docs/product/ACCEPTANCE-MATRIX.md`, `../docs/testing/`.
- Известный сбой: `../ERRORS.md`.
- Роль: `../.codex/agents/<role>.toml` и `roles/INDEX.md`.

## Перед изменением

- Назови ID задачи, владельца смысла и изменяемые файлы.
- Сформулируй один наблюдаемый результат и команду/процедуру проверки.
- Раздели факты, гипотезы и решения.
- Для данных сначала прочитай `protocols/DATA-LIFECYCLE.md`.
- Убедись, что test/private данные не попадут в обучение или tuning.

## После изменения

- Выполни минимальные относящиеся проверки и запиши фактический результат.
- Обнови документ-владелец и сожми `memory/WORKING.md`.
- Оставь один следующий шаг.
- Продвинь только проверенные сведения по `protocols/MEMORY-LIFECYCLE.md`.
- Для передачи используй `protocols/HANDOFF.md`.
