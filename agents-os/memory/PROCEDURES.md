# Процедурная память Vino

Здесь остаются только способы, прошедшие хотя бы один реальный полный проход.
До проверки процедура имеет статус `candidate` и живёт в `protocols/`.

## P-001 — Начало сеанса

1. Прочитать `INDEX.md`, `AGENTS.md`, `PROJECT.md` и `BOOTSTRAP.md`.
2. Прочитать `MEMORY.md` и `memory/WORKING.md`.
3. Открыть одну назначенную задачу и её источник истины.
4. Проверить `ERRORS.md` точным поиском.
5. Назвать результат, файлы и проверку.

- Статус: `verified`.
- Проверено: 2026-09-15 при bootstrap проекта.

## Кандидаты

- Приём данных: `../protocols/DATA-LIFECYCLE.md` — требует первого прохода
  VINO-001.
- Передача результата: `../protocols/HANDOFF.md` — требует первого handoff.
- Продвижение памяти: `../protocols/MEMORY-LIFECYCLE.md` — требует первой
  консолидации после рабочего среза.
