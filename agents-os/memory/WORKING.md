## Текущая цель

Передать проверенное состояние в основной репозиторий BrutForce и загрузить
data-only пакет в версионированную серверную папку вне Git; параллельно закрыть
ручные очереди identity/near-duplicate до frozen splits и получить разрешённые
exports четырёх защищённых retail-каталогов.

## Открыто

- Frozen splits намеренно не выпущены до завершения identity/leakage review.
- Ручные очереди: master 552 verification + 3 annotation; отдельно Telegram
  207 (39 приоритетных), «Своё Вино» 61 + 8, RF100 33, OFF 13, МАВТ 2 + 3,
  AMWine 25, Алкотека 58 и 24 cross-source same-dHash групп.
- Для K&B, ВинЛаб, SimpleWine и LUDING нужен официальный export/permission;
  без него product-level сбор остаётся неполным.
- Права на Telegram media и кейсовые изображения не подтверждены для
  распространения.
- Не подтверждена точная семантика `not_found` в Bash-скрипте кейсодержателя.
- Не определены GPU/CPU окружение, модель, индекс, пороги и post-search функция.
- Переданный в Telegram приватный SSH-ключ без собственной passphrase следует
  отозвать: способ открыть архив находится в том же диалоге. До ротации ключа
  допустимо только явно порученное владельцем ограниченное подключение с
  обязательной проверкой host key; затем ключ должен быть отозван.
- В onboarding snapshot расходятся статусы SSH/sudo, а постоянные tests/CI
  запрещены без отдельного разрешения, что конфликтует с контрактом Vino.
- TCP/22 сервера `sigma-ops` с текущего хоста не отвечает; host key не получен и
  SSH-подключение/выгрузка датасета не выполнялись. Отключать host key checking
  запрещено.
