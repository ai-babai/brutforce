# Иконка приложения: восемь направлений

Исследование 21.09.2026. Галерея: `python3 -m http.server 8772 --bind 127.0.0.1 --directory design/app-icon-study`.

Восемь растровых концептов созданы встроенным imagegen. Для 01 и 07 дополнительно сделаны чистые SVG; галерея показывает их. PNG-оригиналы сохранены. Референс персонажа: существующий mascot-hold-2d-alpha.png из home-composition-27. Текущая иконка скопирована только для сравнения; приложение не изменено.

Концептуальные промпты в prompts.json. Общая инструкция: one square full-bleed app icon, no device/caption/text/watermark, important shapes in central 65%, cream #fbf6ec and burgundy #8f3d42, readable at 48 pixels, original design. Генерация не гарантировала соблюдение всех ограничений: подробно отмечены избыточные детали и необходимость финальной подготовки.

Источники и ограничения исследования — на странице: Apple HIG, Android adaptive icons, App Store Duolingo/PictureThis, Vivino official app page. Рейтинги продукта не доказывают эффективность иконки; позиции чартов не измерялись.

Концепты не являются готовыми пакетами iOS/Android. Круглая маска в галерее — сравнение композиции, не проверка системной adaptive icon. Перед выпуском нужны финальный рисунок, безопасная область, платформенные слои/экспорты и проверка на устройствах.

Проверка: визуально desktop 1280px и mobile 390px; 32/48/64px примеры; круглая/скруглённая форма и тёмная подложка. Рекомендуемый shortlist: 03 (персонаж), 01 (функция).
