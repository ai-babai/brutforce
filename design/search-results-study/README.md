# Мобильная выдача кандидатов — исследование

Задача: https://github.com/ai-babai/brutforce/issues/33

Отдельное исследование, не согласованное изменение основного макета или приложения. Открыть index.html либо запустить `python3 -m http.server 8771 --bind 127.0.0.1 --directory design/search-results-study`.

Три варианта: прямое открытие карточки с доступными альтернативами, равный список, умеренно выделенный лидер. Пять синтетических кандидатов. Источники, ограничения отзывов и план проверки находятся на странице. Растров чужих приложений нет; наброски собственные.

Поведение: выбор кандидата, возврат к выдаче с позицией прокрутки, отказ от всех результатов, объяснение границы существующего ручного поиска/нового фото. Никаких запросов распознавания, камеры и сохранения пользовательских данных.

Проверено 21.09.2026: Chromium, ширины 320/390/1280 px; все три варианта, открытие второго кандидата 2022, возврат к пяти результатам, отказ и переход к границе ручного поиска. Горизонтального переполнения страницы нет. Просмотрен мобильный скриншот 390 px. Пользовательский эксперимент и качество распознавания не проверялись.
