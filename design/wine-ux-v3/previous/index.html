РЕШЕНИЕ ДЛЯ ЭКРАНА

Шесть правок в этом пути

  1. Ошибка сервиса: отдельный экран, повтор — первое действие, камера и галерея рядом.
  2. Совпадений нет: пёс у стойки, поиск по названию — первое действие.
  3. Главная: всегда новый вход, без прошлого снимка и блока продолжения.
  4. Сканирование: линия только на фото; сцена с псом остаётся спокойной.
  5. Кандидаты: компактное исходное фото, его просмотр и возврат к тому же списку.
  6. Карточка: название, винодельня и доступные поля без выдуманной уверенности.
