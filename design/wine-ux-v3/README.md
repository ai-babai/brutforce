# Wine UX v3 · интерактивный макет

Отдельный статический макет мобильного сценария. Продуктовый UI и API не изменены; старый атлас `design/wine-ux-atlas/` сохранён.

## Просмотр

Из корня репозитория:

```sh
python3 -m http.server 8775 --bind 127.0.0.1 --directory design/wine-ux-v3
```

Открыть `http://127.0.0.1:8775/`. Файлы `index.html`, `styles.css` и `app.js` не требуют сборки. Все рабочие ассеты и шрифты локальные; две иллюстрации в разделе исследования загружаются с официальных сайтов и имеют текстовые подписи при недоступной сети.

## Демо-сценарии

- **Главная → Камера → Снимок → Поиск → Долгий поиск → Похожие вина → Карточка.** Демо-таймер показывает долгое ожидание через 5 секунд и выдачу через 11 секунд. Кнопки получения демо-результата внутри телефона нет; прямые состояния выбираются снаружи.
- **Галерея → выбор иллюстративного снимка → Поиск.** Модальное окно моделирует системную галерею, не читает файлы устройства.
- **Похожие вина → Ваше фото → назад к тем же вариантам → карточка → назад к вариантам.** Первое «назад» из списка ведёт на чистую Главную.
- **Нет совпадений → Найти по названию** либо камера/галерея. Это отдельное состояние от ошибки ответа.
- **Ошибка сервера → Повторить поиск** либо камера/галерея; **Нет сети** показано отдельно.
- **Любое состояние → Главная** отменяет таймер поиска и удаляет активный контекст снимка. На Главной нет блока продолжения или удаления снимка.
- **Карточка → Сохранить → Сохранённое** проверяет только локальное состояние макета.

Переключатель слева открывает каждое состояние напрямую. При таких прямых входах контекст снимка задаётся синтетически, чтобы видеть полноценный экран.
Состояние можно открыть ссылкой `?screen=server`, `?screen=results` и т. д.; при переходах параметр обновляется без истории браузера. Кнопки над телефоном задают ширину 320, 360, 390 или 430 px.

В отчёте рядом с макетом есть [исследование](research.md), [черновик сценариев](behavior-audit.md) и переключатель двух иллюстраций ошибки сервиса. Вариант A показан по умолчанию, экран отсутствия сети сохраняет отдельную иллюстрацию с телефоном.

## Границы

Итерация 3.2: [сравнение до/после на iPhone](review.html), [новое исследование](research-iteration-2.md). Это реальные снимки браузера 390×844 с одинаковыми fixtures. Замена фото показана вертикально, ожидание сохраняет крупную сцену отдельно от снимка и статуса. Белые поверхности выдачи FE-057 восстановлены.

Вина, бутылки, исходное фото и ответы полностью демонстрационные. Здесь нет распознавания, измеренной уверенности модели, сетевого запроса, загрузки фотографии или доступа к камере. Изображения бутылок взяты из публичных ассетов текущего приложения; для проверки отсутствующего года у синтетического SVG «Саперави» убрана дата на этикетке. Пользовательские снимки в репозиторий не добавлены. Основания для отдельных элементов и ссылки на источники показаны рядом с макетом как «наблюдение» и «адаптация».

## Итерация 3.3

- `review.html` — актуальное сравнение v3.2 → v3.3, формулировки, iPhone-примеры и источники пяти винных заметок.
- `review-v3.2.html`, `previous-v3.2/` — сохранённые отчёт и кликабельный макет предыдущей итерации.
- Выдача: «Нашли похожие вина»; фото слева, две отдельные кнопки-иконки справа с доступными названиями. Фото раскрывается.
- Ожидание: наклонённый снимок под маскотом, заметка справа; 8 секунд между сменами, растворение 350 мс, пауза. Статус поиска отделён от заметки. Скрытая вкладка и reduced motion останавливают смену. Поиск не ждёт окончания заметки.
- Пример ожидания: `http://127.0.0.1:8775/?screen=slow`. Он остаётся на экране для проверки анимации; вход через камеру/галерею сохраняет автоматическое завершение демо-запроса.
