# Air 3.6 · проверка реализации

26.09.2026. Основание: [AIR-035–038](behavior-v36.feature).

- В браузере на 430×932 и 412×915 проверены композиция Главной, камера и компактный блок фото на UI-009: миниатюра 52×66, подпись рядом, кнопки камеры и галереи справа, основной CTA сразу под блоком, без горизонтального переполнения. На 1280×720 в рамке desktop все действия Главной доступны выше нижней навигации.
- На UI-009 открытие/закрытие миниатюры сохраняет состояние, камера → «Назад» возвращает на тот же экран, выбор нового фото в галерее обновляет миниатюру и запускает новый поиск. Движение общей плашки навигации и вертикальные поля проверены визуально.
- Для проверки камеры и ответа «Ничего не найдено» использовалась временная локальная подмена: нарисованный canvas-видеопоток, синтетический receipt и пустой ответ поиска. Подмена удалена из `apps/web/index.html` до сборки и коммита. Это проверяет интерфейс и переходы; фактический backend и качество распознавания здесь не проверялись.
- `cd apps/web && npm test`: 185/185. `npm run build`: успешно.
