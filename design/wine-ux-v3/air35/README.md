# Air 3.5 — уточнения после проверки Maks

25.09.2026. Пользователь разрешил реализовать эти уточнения без дополнительного согласования.
Air 3.4 сохранён в соседней папке `../air/`. Прототип использует её иконки и базовый CSS,
общие assets v3; это небольшой новый слой, а не перезапись прежней версии.

- Камера: изображение на всю область экрана, крупные действия поверх, градиент для контраста.
  В горизонтальном положении действия справа. В приложении это живое видео и кадр из потока;
  в макете — иллюстративная бутылка, без запроса доступа к устройству.
- Главная: сцена немного крупнее, сканирование и два связанных действия ниже общей группой.
  Повторная фраза «Этикетка целиком, нужная бутылка по центру» удаляется из приложения.
  В предыдущем Air-прототипе этой фразы уже не было. На коротких экранах увеличение сдерживается.
- Лидер: спокойная полоса #f4e8dc → #fbf6ee от края до края экрана, без боковой рамки.
  Внутренние поля совпадают с остальным списком.
- Навигация: один постоянный DOM-элемент; transform 320 ms cubic-bezier(.22,.8,.3,1).
  Раздел меняется сразу, подложка переезжает. При reduced motion — мгновенная смена.
- Primary CTA: Onest / 16 px / 600 / line-height 1.25 на всех экранах.
  Минимальная высота 56 px, на главной 66 px. Вторичные и навигационные кнопки — отдельные роли.

## Проверка

Браузерный QA на 430×932: все 11 состояний без горизонтального overflow,
все иллюстрации загружены, один nav-slider, computed primary 16px/600/20px везде,
где есть основная кнопка. Кадры home/capture/results/server сохранены в review/.
Сравнение до/после использует настоящие снимки двух версий на одинаковой ширине.

У лидера измерены края 0…430 и 0…320 CSS px. Главная и камера визуально просмотрены
на 320×640; действия не перекрываются нижней навигацией. Камера также проверена
на 844×390: видео-область 0…844 по ширине, 0…316 по высоте, навигация снизу;
обе кнопки справа доступны. Проверены камера → галерея → отмена и камера → поиск.

Фактическое движение индикатора подтверждено измерением промежуточных координат
при переключении Сохранённое → Главная: 282, 258, 209, 187, 146, 112, затем 12 px.
Это не только проверка наличия transition в CSS. Reduced motion предусмотрен CSS;
физический мобильный браузер и пользовательское системное предпочтение здесь не проверялись.
