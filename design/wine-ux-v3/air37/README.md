# FE-088 · Air 3.7 · карточка вина

27.09.2026. Решение Макса по [FE-088](https://github.com/ai-babai/brutforce/issues/88),
на основе локального согласованного `wine-card-2a-year-by-winery-20260927.html`.
Этот пакет — дизайн-handoff для UI-007, не изменение работающего приложения.
Основа — [Air 3.6](../air36/README.md); сохраняются фон `#fefdfa`, бордовый
`#8f3d42`, локальные Onest/Playfair, тонкие Phosphor Light, компактная
нижняя навигация и действие сохранения в верхнем правом углу.

## Принятое решение

- Бутылка слева, справа лёгкие факты без плашек: сладость, крепость 17%,
  регион. Перед значениями — ровно три пиктограммы из согласованного 2А:
  капля, бокал и метка карты. Видимых текстовых подписей в герое нет; подписи
  остаются для скринридеров. `17%` сопровождается бокалом, а не иконкой процента.
  В приложении уже установлен Tabler React; в макете те же три SVG встроены
  локально, без CDN.
- Под бутылкой и фактами — винодельня, затем полное название. Год рядом с
  винодельней показывать **только при положительном конечном числовом**
  `Candidate.year` из структурированных данных. Не извлекать его из имени,
  описания, этикетки или URL. На этой реальной карточке год отсутствует:
  `2021` в переключаемом макете — лишь проверка композиции, не атрибут вина.
  При отсутствии года не выводить в шапке «Год не указан» или пустую точку;
  прежняя строка «Год — Год не указан» в нижней сводке допустима.
- При непустом `sourceUrl` — прямая доступная ссылка «Открыть на сайте
  «Своё Вино» ↗» на **исходный URL без подмены**, открытие в новой вкладке
  с безопасным `rel`. При отсутствии `sourceUrl` ссылку не показывать.
  Убрать «Не это вино? Исправить» и вкладки «Обзор / Описание / Источник»
  только из карточки. Сводку бывшего обзора расположить ниже героя.
- Описание при непустом `description` — закрытый по умолчанию семантический
  `<details>` «О вкусе и сочетаниях»; если описание пусто, раскрытие не
  показывать. Между нижней сводкой и раскрытием **один** разделитель;
  остальные тонкие строки внутри сводки остаются. Значения не придумывать.
- Сохранять доступные названия действий и различимую клавиатурную рамку
  фокуса. При переносе в продукт использовать существующие рабочие кнопки
  Назад/Сохранить/навигации, не имитации из макета. У действия внешней
  ссылки объявлять новую вкладку, у фактов — пары термин/значение.

## Воспроизведение

Открыть [прототип](index.html) напрямую из checkout либо запустить из корня
репозитория `python3 -m http.server 8775 -d design/wine-ux-v3` и открыть
`http://127.0.0.1:8775/air37/`. Переключатель «Без года / С годом · пример»
и подпись о 2021 существуют **только в HTML-макете**, не в приложении.
Локальные шрифты — `../assets/`, иконки — `../air/icons.js` (Phosphor Light,
[лицензия](../air/vendor/LICENSE)); Google Fonts, jsDelivr и иные CDN для
шрифтов/иконок не нужны. Для точного сравнения прототип запрашивает исходное
фото каталога по неизменённому URL из согласованного варианта; если снимок
недоступен, остаётся локальный [схематичный силуэт](bottle-study.svg).
Силуэт не является изображением вина из каталога. Продукт использует свой
`Candidate.image`, а не demo URL прототипа и не схематичный силуэт.

Проверка и снимки двух состояний для 320/390/430 px: [QA.md](QA.md).
