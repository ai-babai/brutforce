- На всех трёх ширинах название «Портвейн белый Алушта» занимает две
  строки, винодельня с условным годом — одну; бутылка целиком, факты не
  перекрываются. На 320 px внутренние поля 20 px, начиная с 390 px — 26 px.
  Правая колонка сжимается до 132 px, поэтому длинный регион переносится;
  длинные названия вина и винодельни занимают больше строк, не обрезаются.
  При подстановке длинных названий на 320/390/430 горизонтального скролла нет.
- «Год не указан» остаётся только в нижней сводке; состояние 2021 меняет
  строку винодельни и значение нижнего факта. Пояснение над макетом явно
  маркирует условность года. В шапке не появляется лишний текст о годе.
- Шрифты загрузились локально, изображения целы, ошибок JS и горизонтального
  overflow нет. В HTML одна прямая внешняя ссылка с `target="_blank"`,
  `rel="noopener noreferrer"`; описание закрыто до действия по `<summary>`
  и открывается кликом. Размер строки раскрытия — 55 px, нижнего меню — 62 px.
  Сводка имеет строки по 56 px и один разделитель перед раскрытием.
- Ссылка и раскрытие доступны с клавиатуры: три нажатия Tab с начала
  страницы довели фокус до ссылки с видимой сплошной рамкой `:focus-visible`;
  клик по `<summary>` раскрывает описание. При заблокированном запросе
  изображения отобразился локальный SVG с честным alt. Навигация, Назад и
  Сохранить в этом макете — ненажимаемые визуальные маркеры, не доказательство
  продуктового поведения.

Ограничения: снимки сняты с исходным изображением каталога, доступным по
сети; при недоступности сети остаётся локальный схематичный SVG. Не
проверялись реальный DOM приложения, увеличение системного текста до 200%,
физический телефон, safe-area или переход по внешнему сайту. Ни качество
распознавания, ни работа камеры этим макетом не проверяются.
