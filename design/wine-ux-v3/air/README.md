# Air / 3.4 — отдельный вариант дизайна

Дата: 2026-09-25. Ветка: `codex/design-v3-recovery`. Статус: согласовано Максом 2026-09-25 для BDD, тестов и реализации. Публикация разрешена на площадку Макса; TEST и PROD не обновлять.

Публичный просмотр: [сравнение](https://reps.maks.dzap.pw/v3/air/review.html), [интерактивный макет](https://reps.maks.dzap.pw/v3/air/?screen=home). Локально: `http://127.0.0.1:8775/air/`. [Проверка публикации](publication-qa.md).

Задача: распространить лёгкость заметки о вине и тонкой кнопки паузы на главную, камеру, выдачу и остальные состояния. v3.3 оставлен неизменным по прежнему URL. Этот пакет содержит дизайн и поведенческие требования; продуктовую реализацию выполняет sigma-ops-server-ops-bdd в отдельной ветке. Прежняя граница «не передавать в реализацию» отменена новым поручением пользователя.

## Состав и решения

- `index.html`, `app.js`, `styles.css` — самостоятельный вариант 11 состояний; использует базовый `../styles.css` и общие `../assets/`.
- `review.html`, `review.js` — интерактивное сравнение четырёх экранов до/после и галерея шести дополнительных состояний.
- `review/` — снимки браузера 430×932 с синтетическими данными, сделаны для визуального обсуждения. Не автоматические golden/snapshot tests.
- `research.md` — исследование GPT-6 Sol по первичным источникам Apple и Phosphor, проверено родительским агентом при адаптации.
- `icons.js` — 13 SVG из официального пакета `@phosphor-icons/core@2.1.1/assets/light/`, MIT, текст лицензии `vendor/LICENSE`. Не требует CDN во время просмотра.

Выдача: одна поверхность, лёгкие разделители, небольшая тёплая градация у лидера без скругления и рамки; бутылка 76×132, остальные 56×98. Полные названия, винодельня, год и известные поля сохранены. Незначительное уменьшение плотности обозначено в отчёте как компромисс.

Иконки: единая Light-геометрия, 25–30 px для обычных действий; камера/галерея в выдаче имеют прозрачные области 54×54 px (48×52 на компактном варианте). Иконки снабжены названиями для скринридера. Навигация остаётся подписанной; плавное перемещение фона сохранено. Основные действия остаются плотными винными кнопками.

Главная: непрерывный кремовый → тёплый белый фон, крупная сцена; основная кнопка сохраняет камеру слева и рамку сканирования справа, без повторной подписи. Вторичные действия собраны ближе друг к другу и к основной кнопке по уточнению пользователя. Карточка: бутылка без декоративной плашки. Камера: без тени, рамка видоискателя тоньше. Ошибки: первичное действие и два спокойных вторичных выхода. Ожидание: прежняя композиция и переключаемые заметки сохранены.

Поведение скопировано из v3.3. Исправлена коллизия демонстрационного переключателя: выбор «Ничего не найдено» снаружи показывает пустой ответ, а «Ни одно вино не подходит» внутри выдачи — отказ от кандидатов. Это разные причины одного пути восстановления.

## Проверка композиции

По уточнению пользователя возвращён фотоаппарат слева в CTA главной. Вторичные действия сближены по горизонтали (24 px) и подняты к CTA (8 px). Заголовки камеры, выдачи, поиска, ожидания и сохранённого выровнены по y=92 на контрольном размере. Иллюстрации трёх ошибок занимают одинаковую высоту. В пустом ручном поиске возвращена прозрачная 2D-сцена пса среди бутылок; она скрывается при непустом вводе и после отправки запроса. Действие сканирования расположено под сценой. Фото с заметкой в ожидании поднято на 20 px для связи со сценой. Независимый read-only аудит GPT-6 Sol использован для проверки пустот; размещение основных действий восстановления внизу сохранено осознанно.

Это проверка CSS-вёрстки в браузере, не нативный Safari/iPhone/Android-тест и не пользовательский эксперимент. Камера, фото, каталог и серверные ответы симулируются. Прототип использует прежний локальный сервер 127.0.0.1:8775.
