# Wine UX v3.3 · короткие действия и заметки во время поиска

Проверено 25.09.2026. Ниже разделены **увиденное на официальных iPhone-превью** и **наше решение для макета**. Скриншоты App Store — рекламные кадры приложений, а не доказательство пользовательских предпочтений или результатов тестирования. Предыдущая версия v3.2 называла выдачу «Похожи на вашу этикетку»; слово «этикетка» здесь сужает смысл исходного снимка. В предыдущей [итерации](research-iteration-2.md) две подписанные кнопки стояли одна над другой справа от миниатюры, а фото ожидания было вынесено в отдельную статусную строку.

## Иконки камеры и галереи: реальные iPhone-примеры

1. **Vivino, официальный [App Store](https://apps.apple.com/us/app/vivino-drink-the-right-wine/id414461255?uo=4), [просмотренный кадр](https://is1-ssl.mzstatic.com/image/thumb/PurpleSource221/v4/cd/da/60/cdda6048-aacf-7cdb-88f7-54244a18d8f1/3.jpg/320x480bb.jpg).** Внутри показанного iPhone-экрана отдельная галерея обозначена крупной иконкой изображения без подписи слева от большого круглого затвора. Это именно экран камеры; пара компактных кнопок справа от миниатюры в нём не показана. **Наша адаптация:** оставить различимые пиктограммы камеры и изображения, но поставить два самостоятельных действия рядом с сохранённым снимком на выдаче.
2. **PictureThis, официальный [App Store](https://apps.apple.com/us/app/picturethis-plant-identifier/id1252497129), [просмотренный кадр](https://is1-ssl.mzstatic.com/image/thumb/PurpleSource211/v4/c0/92/36/c09236d0-19c4-598c-ee5b-ee2ece92cdf7/0x0ss.png/320x480bb.jpg).** На нижней панели iPhone-превью маленькая иконка галереи отделена от большого круглого затвора. Так подтверждается привычная визуальная пара «снимок из галереи / сделать фото», но маленькую пиктограмму PictureThis копировать не стоит: у нас кнопки без подписи должны читаться сразу. **Наша адаптация:** пиктограммы около 24–28 CSS px в двух кнопках высотой хотя бы 48 CSS px; подсказки для скринридера «Снять новое фото» и «Выбрать фото из галереи» обязательны. Это предложенные размеры веб-макета, не измерения iPhone-превью.
3. **[Apple Human Interface Guidelines · Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons).** Apple допускает кнопки с одним знаком, но рекомендует узнаваемые символы и достаточную область касания; для нативных интерфейсов ориентир — 44 × 44 pt. **Наша адаптация:** две иконки без видимых подписей допустимы, если силуэты различимы, активная область крупнее самих иконок, а у кнопок есть доступные названия и видимый отклик на нажатие. Нативные pt не следует объявлять равными CSS px.

## Заголовок выдачи

| Вариант | Оценка |
| --- | --- |
| **Похожие вина** | **Рекомендовано:** коротко, честно говорит о кандидатах и не предполагает, что снята именно этикетка. |
| Возможные совпадения | Точно передаёт неопределённость, но звучит технически и без винного контекста. |
| Нашли несколько вариантов | Теплее, но неверно для выдачи с одним кандидатом. |

Для «Похожие вина» подзаголовок может звучать так: «Сравните названия и винодельни, чтобы выбрать нужное». Название экрана и крупный заголовок не стоит дублировать рядом одинаковыми словами. У нынешнего `screenHeader('Похожие вина')` можно оставить короткую навигационную метку, если крупный заголовок будет выражен иначе; выбор окончательного сочетания — редакторское решение, а не вывод из чужого приложения.

## Композиция ожидания и смена заметок

**Наше решение для v3.3:** вернуть слегка наклонённый снимок **под нижнюю часть маскота**, оставив морду и позу собаки открытыми. Справа от снимка — одна короткая винная заметка, без кавычек и ложной атрибуции. Фото остаётся источником текущего поиска и по нажатию открывается; бегущая линия ограничена самим фото, не проходит по иллюстрации. Это возвращает тёплую общую сцену из v3.1, но без большого второго фото и перекрытия героя. Примерная геометрия для 390 CSS px: фото шириной около 80–95 px с наклоном 4–6°, правая колонка заметки занимает остаток доступной ширины; размеры следует проверить на реальном переносе русских строк.

Менять заметку можно мягким растворением примерно за 250–350 мс раз в 8–10 секунд, без движения всего блока и без смены высоты. При `prefers-reduced-motion` оставить текущую заметку статичной. Если заметки меняются автоматически дольше пяти секунд рядом с другим содержимым, нужен способ остановить обновление по [WCAG 2.2, 2.2.2](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html); достаточно явно доступного управления паузой. Не объявлять каждую ротацию как новый статус скринридеру: статус поиска и познавательная заметка решают разные задачи. Скорость и композиция — наша проектная гипотеза, не проверенная пользовательским исследованием.

## Что выбрано после примерки

Основной агент выбрал более разговорное «Нашли похожие вина», подзаголовок «Сравните название и винодельню». Заголовок верхней панели — «Результат поиска». Вместо повторения подписей действий справа стоят две горизонтальные кнопки 56×56 CSS px с пиктограммами 32 px и доступными названиями. На 360 px кнопки 50×52.

В ожидании фото 112×142 px, наклон −6°, под сценой; справа заметка шрифтом Playfair 20 px. Пять заметок плавно меняются раз в 8 секунд, есть пауза. Розовый цвет оставлен в подборке как запасной шестой факт, в ротацию не включён. Уменьшение движения и скрытие вкладки останавливают ротацию. Вместо ленты марок выбраны заметки: случайные марки выглядели бы как реальные промежуточные результаты, которых прототип не получает.

После проверки на 402 px формулировки в интерфейсе сокращены, чтобы карточка не меняла высоту. Источники те же:
- Белое вино тоже можно сделать из тёмного винограда.
- Пузырьки шампанского рождаются при втором брожении в бутылке.
- Красное вино обычно получает цвет от кожицы винограда.
- Дубовая бочка может подарить вину аромат ванили.
- Оранжевому вину цвет даёт кожица белого винограда.
