# Поиск и сохранение · draft 3.7

19.09.2026. Основание — прямое поручение Макса, не копирование новых сторонних экранов. Welcome и камера этой правкой не меняются. Изменения только Atlas, приложение и публикация не затронуты.

## Поиск

Одна обёртка объединяет поле и кнопку лупы. Радиус и граница только у обёртки; поле внутри прозрачно, без самостоятельной рамки. Общий :focus-within применяется при фокусе и поля, и кнопки. Лупа находится справа внутри поля, зона нажатия не менее 48×48 px. Список результатов не прилегает к границе ввода.

Given ручной поиск; When Tab переводит фокус в поле, затем на кнопку; Then фокус обрамляет всю группу, оба края симметричны. Given введено «Демо-вино»; When Enter или кнопка лупы; Then появляется список с отдельным вертикальным отступом. Пустой запрос не запускает поиск.

## Сохранение

Справа в шапке карточки — компактная кнопка с Tabler bookmark и подписью «Сохранить» / «Сохранено». Начальное состояние outline, активное fill; aria-pressed отражает состояние. Это новый согласованный вариант, не ранее утверждённый референс. Широкую рамку под hero не добавляем.

Given карточка A не сохранена; When «Сохранить»; Then заполненная закладка и «Сохранено». When повторное нажатие; Then outline и «Сохранить». Given сохранена A; When выбран другой кандидат B; Then состояние B независимо от A. Состояние живёт только в памяти макета, постоянное хранение не обещается.

Источники: site/design.js (renderPhone, productTop), site/design.css (финальные правила), site/assets/icons.js (Tabler bookmark).

## Точные параметры переноса

Поиск синхронизирован с UI-024 опубликованной реализации: border 1px #cbbbc4, radius 14px, белый фон, grid `minmax(0,1fr) 52px`, min-height 52px и overflow:hidden. Input min-width:0, height 52px, прозрачный фон, без border/outline, padding 0 12px. Submit 52×52px (минимум 48×48px), винный фон #742c46, белая Tabler-лупа 22px. Focus-within: border #b66f8e + box-shadow 0 0 0 2px #b66f8e. Кнопка при focus-visible получает внутреннее кольцо 3px #f3cbdc. После метаданных до списка — 16px; если приложение не показывает метаданные, задать самостоятельный gap 16px.

Save синхронизирован с UI-023: правое действие в grid-header имеет фиксированную область 92×48px; слева «Назад» 48px, между ними title с min-width:0 и ellipsis. У закладки нет рамки, фона, скругления или широкой панели под hero: цвет #742c46, текст 11px/600, nowrap, gap 5px. Иконка Tabler bookmark 21×21, stroke 1.7; active fill только последнего (рисующего) path, не служебного path SVG. Полный SVG в site/assets/icons.js, ключ bookmark.
