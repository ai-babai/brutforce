# Wine UX Atlas

Интерактивный отчёт с референсами и кликабельным макетом мобильного сканера вин для ЛЦТ / РСХБ.

Публикация: https://reps.maks.dzap.pw/view

## Состав и границы

- `site/` — готовая статическая страница, JavaScript, CSS и локальные изображения.
- Камера, галерея, распознавание и каталог демонстрационные; это не приложение и не измерение точности модели.
- Изображения конкурентов — официальные промоскриншоты App Store. Их происхождение указано в `site/assets/manifest.json`.
- Бутылка DEMO вымышленная, создана для макета; сведения об ассетах — в `site/assets/design-asset-sources.json`.
- Шрифт Onest и иконки Tabler хранятся локально. Сборка и установка зависимостей не требуются.

## Локальный просмотр

Из корня репозитория:

```sh
python3 -m http.server 18765 --bind 127.0.0.1 --directory design/wine-ux-atlas/site
```

Открыть http://127.0.0.1:18765/.

### Как обновлять

1. Работать в `design/wine-ux-atlas/site/` на ветке `codex/...`.
2. Кратко дописать историю в `site/index.html`. Для изменённых CSS/JS обновить параметр версии в ссылках, чтобы браузер получил новые файлы.
3. Проверить затронутые сценарии, мобильную ширину и ошибки JavaScript; сохранить изменения отдельным коммитом.
4. По поручению опубликовать `site/` на прежнем адресе, проверить результат и обновить `published-version.json`. Push сам по себе страницу не публикует.

История всех изменений папки:

```sh
git log --oneline -- design/wine-ux-atlas
```

Версии 2 и 3 сохранены отдельными коммитами, без дублирования архивов в дереве проекта. Git позволяет сравнить их и восстановить любую из них.
