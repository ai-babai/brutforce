# Mascot Lab

Отдельный исследовательский сайт и статические примерки. Начни с README.md.

- Каноническая рабочая папка этой задачи: `design/mascot-lab/`. Основной Atlas и приложение не изменять автоматически.
- `site/v1/` — зафиксированная первая итерация с зависимостями, перенесённая из Atlas на ревизии 8ad6deb. Не редактировать архив при работе над следующей итерацией.
- Рабочая вторая итерация: `site/index.html`, `site/lab.*`, `site/prototype.*`.
- Публичные референсы отличать от продуктовых экранов, пользовательских снимков и наших гипотез. Каждому изображению — источник.
- Свёрнутый changelog внизу сохраняет причину и намерение изменения. Коммит и push обязательны для согласованных изменений.
- Публиковать только по поручению пользователя. Для текущей итерации разрешён путь https://reps.maks.dzap.pw/mascots/; /view и сервис распознавания не входят в публикацию.
